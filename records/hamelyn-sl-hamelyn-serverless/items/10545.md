## Summary

Gracias por el contexto: el código actual y la evidencia de producción respaldan la colisión, pero la PR que propone corregir ambos emisores sigue abierta. Mantendría esta issue abierta hasta que la PR se integre y se compruebe la recuperación en producción.

## What This Changes

Solicita que cada aviso de fichero de packing tenga una ocurrencia propia para evitar que el worker bloquee los avisos posteriores como conflictos de payload.

## Best Possible Solution

Integrar una identidad distinta para cada generación de fichero y confirmar en producción un `worker accepted` y la recepción de los correos del almacén.

## Maintainer Decision

Required: false

## Reproduction Assessment

## Solution Assessment

Sí; separar la ocurrencia por generación de fichero resuelve la colisión sin cambiar el contrato de notificación. La PR vinculada propone esa corrección para ambos emisores.
