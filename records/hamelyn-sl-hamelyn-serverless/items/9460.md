## Summary

La incidencia sigue siendo necesaria: el adaptador V2 convierte cualquier HTTP 404 del borrado en `gone`, y el runner consolida ese resultado como retirada correcta aunque el anuncio pueda continuar activo.

## What This Changes

Corregir la retirada de TodoColección para que un 404 de DELETE solo cierre el anuncio tras confirmar semánticamente su ausencia remota.

## Best Possible Solution

Conservar `gone` solo para ausencia confirmada por clave y consulta remota; si el SKU sigue vivo, retirar el identificador verificado y registrar cualquier resultado indeterminado como error reintentable.
