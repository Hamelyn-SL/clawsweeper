## Label Justifications

- `P1`: Protege retiradas de inventario vendido que hoy quedan bloqueadas por batches de publicación en una operación de marketplace activa.
- `merge-risk: 🚨 other`: La nueva prioridad global altera la equidad de planificación entre tipos de operación sin una cuota de progreso para las colas no `withdraw`.

## Summary

El PR aborda el bloqueo real de retiradas y el cambio es correcto, pero modifica la política global de planificación de MarketplaceManager V2; debe quedar abierto para que se confirme explícitamente ese compromiso antes de integrarlo.

## What This Changes

El PR ordena los grupos batch con `withdraw` antes que `publish` y `reprice`, manteniendo FIFO por `operation.startedAt` dentro de cada prioridad.

## Best Possible Solution

Mantener la prioridad de `withdraw` para evitar listings vendidos activos, pero documentar y aprobar la semántica global o introducir una cuota acotada si también debe garantizarse progreso para `publish` y `reprice`.
