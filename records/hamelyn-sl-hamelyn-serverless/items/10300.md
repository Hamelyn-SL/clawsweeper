## Summary

Gracias por los datos: el retraso y la espera horaria están respaldados por el código y las trazas, pero aún falta medir la propagación intermedia para fijar un sondeo seguro; el caso distinto de publicación persistente debe seguir generando un error visible.

## What This Changes

La issue solicita confirmar con rapidez las retiradas eBay aceptadas, evitando una hora de espera cuando la primera lectura aún muestra la oferta publicada.

## Best Possible Solution

Conservar la confirmación remota y añadir relecturas acotadas solo tras un POST aceptado, con límites compatibles con el presupuesto del cron y un error diferenciado al agotarlas.
