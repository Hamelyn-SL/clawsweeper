## Summary

La revisión de código confirma que siguen existiendo rutas v5 sin autenticación y rutas v4 con roles vacíos o sin control de rol; el staging aún no permite validar el comportamiento desplegado. Personas relacionadas: JavierHamelyn (decisión), AlexDiaz-Hamelyn (wrapper) y MarcosTerroso (ruta v5).

## What This Changes

La issue solicita proteger rutas del admin v4/v5 con autenticación y roles explícitos, y restringir la aceptación de audiencias y listas de roles vacías.

## Best Possible Solution

Aplicar autorización explícita por ruta y audiencia apropiada, denegar roles vacíos y definir antes una credencial de servicio o rol operativo acotado para los flujos de almacén que no pueden usar roles interactivos.
