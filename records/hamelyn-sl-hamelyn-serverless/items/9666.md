## Summary

Gracias por el contexto: el código actual sigue dejando rutas v5 fuera de la autenticación del proxy y conserva la autorización con roles vacíos; la comprobación desplegada sigue pendiente. La decisión de acceso debe coordinarse con el gobierno de permisos abierto.

## What This Changes

La issue solicita proteger las rutas del admin que carecen de autenticación o comprobación de rol y corregir los casos en que una lista de roles vacía permite el acceso.

## Best Possible Solution

Alinear los gates de cada ruta con el modelo de roles acordado, denegar configuraciones vacías cuando corresponda y verificar autenticación y autorización en un staging operativo antes de desplegar.
