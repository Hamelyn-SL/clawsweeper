## Summary

La migración sigue siendo necesaria: `dev` conserva el flujo Expo y no contiene `apps/supply-web`; las dependencias de shell, datos y sesión siguen abiertas.

## What This Changes

Migrar a `apps/supply-web` las pantallas de perfil, edición y avatar, preservando sesión, API de usuario y contrato compartido de archivos.

## Best Possible Solution

Implementar el perfil web contra el contrato `GET/PUT /v4/profile`, con validación Zod, invalidación de caché y un adaptador de archivos compartido; verificar sesión expirada, recarga y borrado de avatar.
