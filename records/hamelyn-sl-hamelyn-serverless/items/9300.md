## Summary

Gracias por el contexto: el guard actual no genera una señal cuando el snapshot anterior era `Sold`, por lo que este relisting `For Sale/MK_ONLY` permanece fuera de la retirada. No es el mismo caso ya corregido de IDs históricos duplicados y debe seguir abierto.

## What This Changes

Investigar la republicación de un listing de Discogs retirado y crear una retirada canónica segura cuando reaparece `For Sale` sin mirror local.

## Best Possible Solution

Mantener el guard conservador general y añadir para Discogs una ruta acotada que confirme en API viva el relisting de un stock `WITHDRAWN`, encole su ID y deje trazabilidad del origen antes de automatizar cohortes mayores.
