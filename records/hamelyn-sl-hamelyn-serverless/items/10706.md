## Summary

La issue describe una limitación real y sigue pendiente: el flujo de Amazon exige seguimiento tanto para seleccionar pedidos como para validarlos y construir la confirmación. El PR relacionado reconoce expresamente el bloqueo y pide no activar el piloto hasta decidir cómo confirmar esos envíos.

## What This Changes

Solicita una vía para confirmar a Amazon los pedidos Postlibri que no tienen número de seguimiento.

## Best Possible Solution

Definir y probar un método admitido por Amazon para confirmar envíos ordinarios sin seguimiento, y habilitar el piloto solo después de validar su efecto en las métricas de la cuenta.
