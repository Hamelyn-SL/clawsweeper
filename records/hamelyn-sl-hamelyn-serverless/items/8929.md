## Summary

Gracias por el contexto. La funcionalidad sigue siendo necesaria: el flujo actual conserva una gaveta escaneada o elegida manualmente, pero no decide automáticamente un destino de revisión.

## What This Changes

Añadir una regla que asigne automáticamente la gaveta de destino durante la revisión de productos.

## Best Possible Solution

Definir una matriz operativa de destino con reserva de elección manual y aplicarla de forma centralizada antes de persistir `products.$.drawer`.
