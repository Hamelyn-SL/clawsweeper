## Summary

Gracias por el contexto. La funcionalidad sigue siendo necesaria: el kiosco actual no clasifica ni persiste un destino automático para los artículos apartados durante la revisión.

## What This Changes

La petición propone clasificar automáticamente artículos revisados en destinos operativos y gestionar una caja de granel con ciclo persistido.

## Best Possible Solution

Acordar primero la matriz de clasificación y el contrato de persistencia; después dividir UI, máquina de estados, API y modelo en entregas con pruebas de transición y corrección.
