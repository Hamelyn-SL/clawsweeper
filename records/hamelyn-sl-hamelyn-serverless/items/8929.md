## Summary

Gracias por el contexto. La funcionalidad sigue siendo necesaria: el flujo actual separa entrada y revisión, rechaza baja demanda sin destino persistido y no modela el ciclo operativo de una caja `G-*`.

## What This Changes

La issue solicita clasificar automáticamente artículos de revisión y gestionar su destino, incluida una caja de granel con control operativo.

## Best Possible Solution

Definir un contrato único de clasificación y extender el flujo de `INVENTORY` para representar, de forma auditable, apertura, cierre, conteo y correcciones de cada caja `G-*`.
