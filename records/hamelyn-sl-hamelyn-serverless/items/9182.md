## Summary

Mantener abierta esta incidencia como canónica: el mismo cron agotó el reintento ante `429` en varios mercados, y el código actual aún permite que un límite sostenido de SP-API termine la búsqueda.

## What This Changes

La incidencia registra un `429` terminal tras el segundo reintento de `searchOrders` para Amazon IT en `/api/amazon-order-recovery`.

## Best Possible Solution

Medir el resultado final por marketplace y ajustar el limitador o la espera de `searchOrders` si los `429` terminales correlacionados impiden recuperar pedidos.
