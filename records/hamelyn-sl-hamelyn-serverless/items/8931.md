## Summary

El PR corrige desalineaciones reales de V2, pero no es seguro fusionarlo aún: Amazon usa un corte posterior al informe y el espejo de BigQuery no rellena las filas existentes tras añadir columnas.

## What This Changes

## Best Possible Solution
