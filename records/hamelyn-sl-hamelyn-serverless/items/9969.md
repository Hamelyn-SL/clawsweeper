## Summary

La corrección de atribución B2B es coherente con el contrato de picking, pero la nueva fuente procesa todo `pickingOp` en cada consulta de Ventas; debe acotarse antes de integrar.

## What This Changes

La rama añade una fuente SQL común que desglosa las ventas B2B por producto con picking `DONE` y actualiza las agregaciones de Ventas para usarla.

## Best Possible Solution

Conservar el desglose por unidad, pero limitar `completed_picks` a operaciones B2B y al intervalo o conjunto de pedidos necesario para cada consulta, con cobertura de fallbacks y deduplicación.
