## Summary

Gracias por el reporte y por la reproducción concreta: el flujo actual confirma que la guarda puede bloquear al run elegible después de un evento en draft. La corrección está en una PR abierta y aún requiere validación en GitHub Actions; mantengamos esta issue abierta hasta que se integre.

## What This Changes

La issue pide que la guarda de PR Lifecycle ignore runs anteriores que no podían solicitar reviewer, sin perder la protección contra asignaciones duplicadas.

## Best Possible Solution

Integrar una corrección que excluya de la detección de concurrencia los runs que no podían solicitar reviewer, conservando la protección entre runs elegibles.

## Solution Assessment

Sí: filtrar los runs que no pueden solicitar reviewer mantiene la guarda de concurrencia para runs elegibles y aborda la causa demostrada.
