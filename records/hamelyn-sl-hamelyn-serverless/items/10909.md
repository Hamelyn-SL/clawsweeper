## Summary

El cambio cubre la regla solicitada, pero queda un defecto accionable: si falla la consulta de historial, el precheck aún puede resolver automáticamente una issue abierta de proveedor como recuperada. La revisión anterior ya señaló este caso y sigue visible en el head actual del PR.

## What This Changes

El PR exige un episodio continuo de tres horas para admitir 5xx de proveedor y actualiza la consulta de historial, la evidencia de las issues, las pruebas y la documentación.

## Best Possible Solution

Mantener bloqueada la resolución automática de issues de proveedor cuando no se pudo verificar el historial, y cubrir ese escenario con una prueba focalizada.

## Solution Assessment

Sí para el umbral de 5xx descrito: el episodio consecutivo es más específico que acumular cortes separados. Antes de integrar, hay que preservar la protección de estado cuando no se pudo consultar el historial.
