## Summary

La incidencia sigue siendo necesaria: `dev` aún deja el 405 de un verbo no exportado fuera de `defineRoute`, y una PR abierta ya concentra la corrección. Debe permanecer abierta hasta que esa PR se revise e integre.

## What This Changes

Solicita que las rutas API v6 respondan a métodos no admitidos con el envelope JSON estándar, `Allow` y `x-request-id`.

## Best Possible Solution

Integrar una interceptación central basada en `allContracts`, con cobertura de métodos permitidos, `HEAD`, `OPTIONS` y rutas desconocidas sin alterar su 404.
