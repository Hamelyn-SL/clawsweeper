## Summary

Gracias por el reporte y por el diagnóstico: las muestras confirman que la descarga de ofertas interpreta bajas del catálogo como páginas sospechosas. Mantengo la issue abierta porque su PR de resolución sigue abierto; la comparación base→PR y la prueba de comportamiento descrita en ese PR respaldan el cambio propuesto.

## What This Changes

La descarga de ofertas de Casa del Libro debe clasificar como `gone` las bajas que devuelven una portada con HTTP 200, en lugar de dejarlas como páginas sin componente de lista.

## Best Possible Solution

Integrar o resolver el PR vinculado y conservar las guardas que distinguen una baja real de una portada normal, un dominio extranjero o una respuesta incompleta.
