## Summary

El defecto sigue activo en `dev`: las cuatro rutas sustituyen el stock del pedido sin reclasificar la unidad original ni registrar de forma consistente el historial; falta decidir su semántica contable y autorizar el backfill.

## What This Changes

La incidencia propone corregir las sustituciones de picking para evitar stocks `SOLD` huérfanos, doble conteo analítico y pérdida de trazabilidad en `replacedProducts`.

## Best Possible Solution

Acordar un motivo explícito para pérdida en picking, corregir atómicamente las cuatro rutas para reclasificar el original y acumular `replacedProducts`, y ejecutar después un backfill aprobado e idempotente.
