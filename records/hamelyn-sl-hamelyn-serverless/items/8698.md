## Label Justifications

- `P1`: El defecto activo infla señales de demanda y rotación que alimentan decisiones de precio.
- `impact:data-loss`: Persisten estados de stock y de venta incoherentes con el pedido que realmente consumió la unidad.

## Summary

El defecto sigue activo en `dev`: las sustituciones actualizan el pedido con la alternativa, pero no reclasifican de forma consistente el original ni conservan siempre la trazabilidad; las consultas analíticas cuentan ambos motivos de venta por stock.

## What This Changes

Corregir las sustituciones de picking para evitar stocks `SOLD` huérfanos, registrar cada reemplazo y preparar un backfill auditado sin duplicar ventas en analítica.

## Best Possible Solution

Acordar la razón de retirada, centralizar la sustitución para reclasificar el original y registrar el par, y ejecutar después un backfill independiente, reversible y auditado; dejar el CAS de marketplace en una incidencia o PR acotada.
