## Label Justifications

- `P1`: El defecto activo puede inflar señales de demanda y rotación que alimentan decisiones de precio en producción.
- `impact:data-loss`: La sustitución deja datos de inventario y venta persistentemente incoherentes con el pedido real.

## Summary

El problema sigue presente en `dev`: las rutas de sustitución retiran la alternativa y cambian el `ordersell`, pero no conservan de forma coherente la trazabilidad ni evitan que el original siga contando como venta.

## What This Changes

Corregir las sustituciones de picking para que el stock original no quede vendido sin referencia, registrar el historial de reemplazos y evitar el doble conteo de ventas.

## Best Possible Solution

Definir una única semántica para la pérdida durante picking y aplicarla atómicamente en todas las rutas: reclasificar el original, limpiar `soldAt`, registrar cada par con `$push` y separar el backfill auditable.
