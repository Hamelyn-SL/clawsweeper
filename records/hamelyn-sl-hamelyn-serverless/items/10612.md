## What This Changes

El PR modifica el cliente HTTP y los comandos del CLI para evitar reintentos de escrituras con respuesta, detener el fallback ante configuración TOML inválida, ampliar el timeout y acotar errores de jq, además de ajustar tests y la skill.

## Best Possible Solution
