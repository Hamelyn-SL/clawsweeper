## Summary

Gracias por el contexto: la redirección incorrecta está confirmada y la cobertura actual del código y las pruebas coincide con el fallo; el comentario previo identifica que hay que coordinar también la delegación al ecommerce.

## What This Changes

Se solicita que `/uk/buy` y `/cat/comprar` sirvan el ecommerce con HTTP 200 y sin redirecciones, para evitar saltos adicionales desde las URL antiguas.

## Best Possible Solution

Alinear las rutas de delegación del microfrontend, las exclusiones de redirección de mercado y los redirects; conservar pruebas de HTTP 200 sin `Location` para ambas rutas y de un solo salto desde las URL antiguas.
