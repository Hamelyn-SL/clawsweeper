La corrección aún requiere coordinar la delegación del storefront antes de cambiar prefijos; el PR que introdujo estas rutas ya está integrado, pero no resuelve el comportamiento solicitado.

## Best Possible Solution

Alinear redirecciones, exclusiones de país y delegación de microfrontends para que ambos prefijos sirvan el storefront; validar después HTTP 200 sin `Location` y un único salto desde las URLs antiguas.
