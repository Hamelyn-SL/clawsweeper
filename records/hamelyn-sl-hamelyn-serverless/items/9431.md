## Summary

Este PR sigue siendo necesario, pero no es seguro integrarlo todavía: la recuperación puede cancelar un workflow y perder su relanzamiento si la cancelación tarda más de 24 segundos o el relanzamiento falla transitoriamente.

El PR mueve seis workflows de housekeeping al runner self-hosted Lyno y añade un watchdog que conmuta `HOUSEKEEPING_RUNS_ON` y recupera runs atascados.

## Best Possible Solution

Persistir de forma duradera los runs cancelados pendientes y reintentarlos hasta que GitHub confirme el relanzamiento, con límites e idempotencia para evitar duplicados.
