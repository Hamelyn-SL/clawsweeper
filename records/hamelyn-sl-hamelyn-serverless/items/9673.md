## Summary

La petición sigue siendo necesaria, pero no debe implementarse hasta decidir si el valor representa el coste histórico del ejemplar o el precio de compra vigente del catálogo.

## What This Changes

Cambiar el `unit price` de las facturas agrupadas de MercadoLibre para FedEx México por un precio de compra de Supply, tanto para libros como para nuevas categorías.

## Best Possible Solution

Definir `stocks.priceBuy` o `products.priceBuy` como fuente comercial, conservar la misma fuente en PDF y payload FedEx, y cubrir ambos grupos con pruebas de importes.
