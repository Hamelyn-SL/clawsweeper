## Label Justifications

- `P1`: La conciliación de cancelaciones puede dejar pedidos cancelados disponibles para fulfillment o alterar transiciones ya procesadas.
- `merge-risk: 🚨 compatibility`: La rama cambia a v1.3 todas las solicitudes de Order Update y modifica la prioridad de envío derivada del proveedor.

## Summary

El PR sigue siendo necesario, pero no es seguro integrarlo aún: la nueva conciliación puede omitir cancelaciones, repetir transiciones y saturar el cron; además, la prueba publicada no ejecutó la ruta decisiva.

## What This Changes

El PR reemplaza el sondeo individual de cancelaciones de AbeBooks por `searchOrders` y usa `shipping.speed` de la API v1.3 para elevar prioridades.

## Best Possible Solution

Mantener una conciliación idempotente y recuperable con cursor o fallback local, consultas por lote y cobertura de artículos terminales; separar la decisión de prioridad `speed` si Operaciones no la valida.
