## Summary

La PR sigue siendo necesaria para eliminar el runner duplicado, pero actualmente puede publicar un veredicto de convenciones para un SHA distinto del que validó; debe corregirse antes de fusionarla.

## What This Changes

Integra la comprobación de convenciones en `[Bot] PR Lifecycle`, elimina `conventions.yml` y actualiza la documentación del gate y del carril directo.

## Best Possible Solution

Obtener primero el SHA vivo del PR, usarlo tanto para el checkout como para el payload y adjuntar el resultado a ese mismo SHA; conservar la ejecución exclusiva de scripts de la rama base.
