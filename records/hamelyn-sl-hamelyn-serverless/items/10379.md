## Label Justifications

- `impact:other`: El impacto concreto es una operación de almacén bloqueada por una petición BringBins cancelada; no encaja en las categorías específicas disponibles.

## Summary

La incidencia sigue abierta: en `main`, dos planes pueden compartir la misma instrucción BringBins y el rollback cancela la última línea creada sin identificar qué invocación es su propietaria. El informe aporta un caso de producción y una reproducción local del flujo anterior.

## What This Changes

Evitar que generaciones NE-EX simultáneas para el mismo OP cancelen peticiones BringBins que pertenecen a la generación que sí se confirma.

## Best Possible Solution

Identificar cada petición BringBins con un ID de plan y limitar el rollback a líneas de esa invocación, protegiendo además la planificación concurrente del mismo OP.
