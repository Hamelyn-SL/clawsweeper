## Summary

La incidencia sigue siendo necesaria: la firma procede de una creación HTTP correcta que queda temporalmente `paused`, pero el código la registra como advertencia mientras la trata como alta completada; falta decidir su tratamiento operativo.

## What This Changes

La incidencia pide que la creación de anuncios de Mercado Libre no repita la firma `paused` con `picture_download_pending` como causa de error.

## Best Possible Solution

Definir `paused/picture_download_pending` como estado asíncrono explícito: conservar el anuncio creado, medirlo separadamente y alertar solo si no se reactiva dentro de una ventana acordada.
