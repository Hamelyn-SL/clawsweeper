## Label Justifications

- `P2`: Es un piloto de marketplace aún no programado, pero el defecto puede duplicar listings cuando se ejercite la nueva ruta.
- `merge-risk: 🚨 other`: Una recuperación de persistencia incompleta puede repetir un efecto remoto ya confirmado y crear listings duplicados.

## Summary

El piloto sigue siendo trabajo útil, pero un fallo doble de persistencia tras publicar remotamente puede volver a seleccionar el SKU y duplicar el listing; además falta prueba real del flujo Discogs/cron antes de merge.

## What This Changes

El PR incorpora el piloto F2 de `MarketplaceManager` para Discogs, con runners, estado persistido, rate limiting, ruta cron manual y documentación asociada.

## Best Possible Solution

Convertir el fallo doble posterior a publish en un estado que nunca vuelva a publicar automáticamente hasta reconciliar el listing remoto, y aportar una ejecución real redactada de create/recovery/tick antes del switchover.
