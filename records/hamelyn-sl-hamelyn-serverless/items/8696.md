## Summary

El PR aporta una mejora útil del contrato OpenAPI, pero el mecanismo de deprecación todavía no cumple varias garantías públicas declaradas y no está listo para integrar.

## What This Changes

El PR registra `ApiError` como esquema OpenAPI reutilizable y añade una política de deprecación basada en `deprecated.sunset` para las operaciones de la API.

## Best Possible Solution

Conservar el esquema `ApiError`, pero completar una única utilidad de deprecación que valide el plazo y las fechas al registrar rutas, forme cabeceras estándar y se aplique también a respuestas CORS y raw.
