## Summary

Gracias por el contexto: `dev` conserva el alias fijo que produjo el 401 y la alerta aún usa `priority:p1`; además faltan las señales solicitadas. La incidencia relacionada resolvió el disparo inicial, no estos restos operativos.

## What This Changes

Reparar la ejecución verificable del watcher de Amazon SE tras el report, corregir las alertas automáticas y añadir señales para deuda BATCH y FBA vendible.

## Best Possible Solution

Hacer que el despliegue espere y confirme la promoción real, ejecutar un smoke M2M en `dev` y `master`, migrar ambas acciones de alerta a `P1` y emitir métricas separadas para BATCH >1 día y FBA vendible.
