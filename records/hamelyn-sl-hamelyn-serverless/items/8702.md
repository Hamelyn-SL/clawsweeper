## Summary

Gracias por la contribución. El objetivo de descubrimiento está bien encaminado, pero las tres rutas nuevas no preservan el CORS que ofrece la API canónica; un cliente web con preflight queda bloqueado antes de seguir el `308`.

## What This Changes

El PR añade alias de descubrimiento de API, enlaces SSR de documentación y recursos en `llms.txt` para que la tienda apunte a `api.hamelyn.com`.

## Best Possible Solution

Mantener los alias `308`, pero equipararlos al contrato CORS público de `api.hamelyn.com` y actualizar el cuerpo del PR para describir enlaces HTML SSR, no cabeceras HTTP `Link`.
