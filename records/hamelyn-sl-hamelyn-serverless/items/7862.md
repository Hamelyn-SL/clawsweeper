## Summary

La tormenta de reconexiones ya quedó resuelta en `dev`, pero esta issue conserva una decisión de producto pendiente: Analytics Supply aún necesita MongoDB para enriquecer eventos autenticados con `mongo_user_id`.

## Best Possible Solution

Mantener el arreglo de reconexiones y decidir si `mongo_user_id` debe conservarse síncrono o enriquecerse después de registrar el evento.
