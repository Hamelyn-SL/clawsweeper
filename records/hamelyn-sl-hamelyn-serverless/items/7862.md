## Summary

La tormenta de reconexiones ya queda evitada en `dev`, pero siguen pendientes dos decisiones explícitas: la frescura automática de configuración y el coste de enriquecer Analytics Supply con Mongo.

## What This Changes

Evitar recargas de configuración Mongo en conexiones warm y decidir cómo conservar la frescura de configuración y el enriquecimiento de usuarios en Analytics Supply.

## Best Possible Solution

Acordar el contrato de frescura y de `mongo_user_id`, y después aplicar una única implementación que preserve la reutilización warm y cubra ambos modos con pruebas dirigidas.

## Maintainer Decision

Required: true

Kind: product_direction

Question: ¿Debe `ConfigService` conservar el modelo actual de configuración por cold start o incorporar refresco warm acotado, y debe Analytics Supply seguir resolviendo `mongo_user_id` durante la petición?

Rationale: El código actual elimina la reconexión, pero las dos alternativas cambian la latencia, la consistencia de configuración y el contenido analítico observado.

Likely owner: JavierHamelyn

Owner reason: Su historial en Analytics Supply y el comentario más reciente conectan directamente ambas decisiones.

Owner confidence: high

Options:

- **Mantener el contrato actual (recommended):** Conservar configuración por cold start y enriquecimiento síncrono de `mongo_user_id`, documentando que los cambios normales requieren una nueva instancia.
- **Adoptar frescura acotada:** Añadir TTL y single-flight con stale-on-error, preservando refrescos explícitos de MercadoLibre y definiendo su prioridad.
- **Desacoplar Analytics:** Mantener `auth0_user_id` en la petición y mover el enriquecimiento de `mongo_user_id` a un proceso posterior.

## Reproduction Assessment

No para la tormenta original: el código actual reutiliza una conexión warm sana sin recargar configuración. El comportamiento restante de configuración sin TTL sí se confirma por inspección de fuente.

## Solution Assessment

No está claro aún: el arreglo parcial es seguro para reconexiones, pero elegir TTL o configuración por cold start requiere decidir el contrato de frescura y el enriquecimiento analítico.
