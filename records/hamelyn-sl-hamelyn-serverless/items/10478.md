## Summary

Gracias por el análisis: el selector FIFO limitado sigue dejando las ventas nuevas detrás del lote. El antecedente de capacidad de MercadoLibre se aplazó, pero no decide la protección de ventas normales en estos canales; hace falta acordar ese reparto antes de cambiarlo.

## What This Changes

La issue solicita que las ventas normales no esperen detrás de grandes lotes B2B y que se acote el tiempo de retirada en TodoColección, AbeBooks, eBay y MercadoLibre.

## Best Possible Solution

Definir por canal una política medible que atienda ventas recientes sin impedir el avance del lote, respetando cuotas, reintentos y confirmación remota; validar latencia de ambas colas y alertar cuando se incumpla el objetivo acordado.
