## Summary

La incidencia sigue siendo necesaria: el flujo vigente recupera el ID ante `already_reference` y confirma éxito sin actualizar el precio remoto, por lo que puede retirar `needsUpdatePrice`.

## What This Changes

Corregir la recuperación de listings existentes de TodoColeccion para que las discrepancias de precio no queden fuera del selector de reprice.

## Best Possible Solution

Al recuperar un listing existente, ejecutar la actualización completa con el precio del maestro y conservar el trabajo pendiente ante error o `success=false`; después, revalidar los cinco SKU con un canario autorizado.
