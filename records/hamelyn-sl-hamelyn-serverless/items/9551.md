## Summary

La incidencia sigue siendo necesaria: el selector actual solo procesa mirrors con `needsUpdatePrice=true`, mientras los ejemplos documentados quedan fuera y no existe una reconciliación remota que los vuelva a señalar.

## What This Changes

La incidencia solicita investigar por qué algunos listings activos de TodoColeccion divergen entre Mongo y la API remota sin activar `needsUpdatePrice`.

## Best Possible Solution

Definir el precio maestro como contrato explícito o documentar la excepción, añadir detección acotada de drift remoto y marcar solo listings confirmados para reprice con canario previo.
