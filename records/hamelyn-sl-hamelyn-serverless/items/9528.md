## Summary

Mantener abierto: el PR amplía una autorización que retira stock, pero un ✅ raíz anterior puede seguir siendo visible tras un re-adjunto. Al convertir el 20–80 % de no servido en aviso, esa reacción antigua puede ejecutar el XLSX sustituto sin una aprobación fresca.

## What This Changes

El PR permite ejecutar pedidos B2B con ✅ autorizado hasta 200.000 unidades y 80 % no servido, y ajusta avisos y escalados para clientes provisionales.

## Best Possible Solution

Conservar una aprobación inequívocamente ligada al dry-run: tras un re-adjunto, exigir HITL o una señal nueva verificable antes de cualquier ejecución por ✅, y decidir explícitamente si los topes 80 %/200.000 son política permanente.
