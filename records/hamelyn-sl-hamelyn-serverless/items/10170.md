## Summary

El PR aborda el caso abierto de listings Amazon ES con cantidad superior a uno, pero añade una escritura automática que reduce la cantidad remota a 1. Como esa elección operativa no está resuelta y el issue relacionado pide no modificar cantidades comerciales, mantendría el PR abierto hasta que el equipo confirme el alcance.

## What This Changes

Añade la clasificación `EXCESS_QUANTITY` y un flujo acotado para corregir listings de Amazon ES, comprobar pedidos y confirmar el resultado remoto antes de cerrar la operación.

## Best Possible Solution

Si se autoriza la corrección automática, conservar las guardas de stock, pedidos y estado remoto y verificar el orden de despliegue del gestor y el report; si no, mantener `EXCESS_QUANTITY` como clasificación sin escrituras remotas.
