## Summary

El PR ofrece una solución técnica coherente, pero el comportamiento deseado sigue requiriendo decidir si TodoColección debe publicar con placeholder o retener el stock hasta disponer de foto propia.

## What This Changes

El PR sustituye la URL Bunny rota por `HAMELYN_DEFAULT_IMAGE` cuando falta `hasBunnyImage` en las altas y actualizaciones de TodoColección.

## Best Possible Solution

Acordar la política de publicación para productos sin foto Bunny; si se acepta la publicación degradada, mantener este fallback y verificar después el reemplazo por una imagen real.
