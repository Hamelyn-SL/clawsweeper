## Summary

El cambio técnico es coherente y aborda la incidencia enlazada, pero altera una política comercial aún no decidida: publicar con placeholder frente a retener el stock sin foto.

## What This Changes

El PR incorpora `getTodoColeccionMainImage` para usar `HAMELYN_DEFAULT_IMAGE` cuando un producto no tiene `hasBunnyImage`, tanto al crear como al actualizar listings.

## Best Possible Solution

Aprobar o rechazar explícitamente la publicación con placeholder; si se aprueba, mantener el helper compartido y documentar el ciclo de sustitución al llegar una imagen Bunny.
