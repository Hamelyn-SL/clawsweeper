El cambio aborda el fallo descrito y la prueba aportada confirma que una portada genérica no llega al uploader al crear el producto. Mantengo este PR abierto porque sigue vinculado a la issue abierta que declara cerrar; la limitación del upsert de productos existentes está documentada y no es una regresión de este parche.

## What This Changes

El PR descarta `finalImage` cuando el OCR de la portada coincide con un patrón de imagen genérica y añade tests del helper.

## Best Possible Solution

Integrar una corrección acotada para la creación de productos y mantener separada cualquier limpieza de portadas genéricas ya persistidas, que requiere distinguirlas de imágenes guardadas válidas.
