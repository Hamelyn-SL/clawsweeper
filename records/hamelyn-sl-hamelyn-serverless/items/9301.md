## Summary

El PR sigue siendo necesario: amplía de forma acotada el guard de persistencia para el caso Discogs `Sold` → `For Sale/MK_ONLY` y conserva los filtros previos de retirada. La ruta de encolado mantiene la comprobación de maestro `WITHDRAWN`, fecha y `listing_id`; queda una validación operativa limitada antes de confiar en el canario.

## What This Changes

El PR habilita solo para Discogs que una foto anterior `Sold` del mismo SKU y `listing_id` respalde un huérfano actual `For Sale/MK_ONLY`.

## Best Possible Solution

Mantener el opt-in exclusivo de Discogs y validar con el canario aprobado que la coincidencia genera una sola señal durable sin alterar el maestro ni retirar un listing legítimo.
