## Summary

Este PR corrige una incidencia real, pero introduce un bloqueo de cola cuando un listing marcado desaparece antes de pasar a `Draft`; debe repararse antes de integrar.

## What This Changes

El PR recupera huérfanos de Discogs tras `Sold` → `For Sale/MK_ONLY` y revalida la rotación antes de publicar.

## Best Possible Solution

Distinguir el 404 confirmado de una interrupción recuperable: limpiar o avanzar el marcador solo para el listing ausente y conservarlo únicamente si sigue existiendo como `Draft`.
