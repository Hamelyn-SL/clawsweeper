## Summary

La necesidad central sigue abierta: `dev` solo ofrece ediciones relacionadas desde una PDP de ISBN, no una ruta autoritativa, paginada y canónica por obra.

## What This Changes

Crear un piloto MX de página de obra que agrupe ediciones de un `workId`, con filtros, SEO, secciones reutilizadas y redirecciones desde ISBN eliminados.

## Best Possible Solution

Acordar primero el patrón de URL canónica y el contrato de datos de obra; después implementar el piloto MX en entregas separadas para datos, UI, SEO/redirecciones y validación.
