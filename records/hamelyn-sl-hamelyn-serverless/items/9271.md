## Summary

La separación entre base persistida y oferta es coherente, pero esta PR cambia la interpretación de datos existentes sin una transición ejecutable y comprobable; no debe integrarse hasta acordar y asegurar el cutover.

## What This Changes

La rama deja `products.priceBuy` como base persistida y deriva el bonus de `featured` al calcular las ofertas en Supply, Admin, API y precios.

## Best Possible Solution

Introducir una transición segura para datos antiguos o ejecutar una conversión aprobada, verificable y bloqueante antes de habilitar los nuevos lectores y escritores en producción.
