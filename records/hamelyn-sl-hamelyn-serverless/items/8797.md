## Summary

El PR cambia el dispatch diario de Alibris y el valor por defecto del exportador para usar Mongo vivo, conservando BigQuery como alternativa manual explícita.

## Best Possible Solution

Integrar el cambio y desplegar la definición de Cloud Scheduler para que el purge diario pase `source=mongo`, manteniendo el selector manual de BigQuery para comprobaciones acotadas.
