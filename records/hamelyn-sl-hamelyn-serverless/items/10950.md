## Summary

El cambio aborda el problema reportado, pero queda un defecto reproducible en la alternativa que usa el precio del Excel: el parser lo redondea a céntimos antes de facturarlo, por lo que el total puede no coincidir con el importe pactado. La Asamblea también lo reprodujo.

## What This Changes

El PR incorpora precios pactados para pedidos deco, prioriza el SKU indicado en el Excel y actualiza pruebas y documentación B2B.

## Best Possible Solution

Conservar la precisión disponible en el precio del Excel hasta el cálculo del importe facturado y añadir una regresión que cubra el total de varias unidades.

## Solution Assessment

No del todo: el enfoque de precios pactados y SKU cubre el comportamiento solicitado, pero el precio del Excel debe conservar precisión para evitar el desajuste reproducido.
