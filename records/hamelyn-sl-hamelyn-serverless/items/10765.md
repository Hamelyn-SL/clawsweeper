## Summary

Gracias por el diagnóstico: los datos aportados muestran un anuncio activo y comprable detrás de un tombstone vendido. El código actual sí puede omitirlo: la recuperación exige evidencia `MK_ONLY` en la foto anterior y respeta una gracia de 48 horas, condiciones que este caso no cumple.

## What This Changes

La issue solicita que la reconciliación de MercadoLibre MX detecte y retire anuncios hermanos activos cuando el SKU vendido ya tiene un tombstone `WITHDRAWN`.

## Best Possible Solution

Añadir un carril acotado que rearme la retirada solo tras releer el stock maestro como `SOLD/WITHDRAWN` y confirmar por API un anuncio hermano activo; proteger la mutación con CAS de identidad, timestamp y ausencia de operación, y reutilizar el consumidor existente que busca todos los anuncios por SKU.
