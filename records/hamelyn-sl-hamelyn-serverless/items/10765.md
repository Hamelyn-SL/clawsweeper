## Label Justifications

- `P1`: El anuncio remoto activo y comprable detrás de una retirada SOLD puede provocar sobreventa y cancelaciones.
- `impact:other`: El caso expone una inconsistencia de estado entre el stock retirado y un listing remoto aún comprable.

## Summary

La evidencia y el diagnóstico del comentario encajan con el flujo actual: el reporte cuenta `paused` como vivo, pero la recuperación conserva las guardas de snapshot anterior y 48 horas, que este caso SOLD reciente no supera. No hay una corrección integrada ni un PR abierto que resuelva este caso.

## What This Changes

El reporte diario de MercadoLibre MX deja sin retirar un anuncio hermano activo y comprable cuando el SKU ya tiene una retirada `SOLD` reflejada como tombstone.

## Best Possible Solution

Añadir una recuperación específica y estrecha para tombstones `SOLD`: releer el estado maestro y verificar por API que el hermano sigue activo antes de rearmar la retirada, con controles de concurrencia y pruebas que protejan el stock vendible.
