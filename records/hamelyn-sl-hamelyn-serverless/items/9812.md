## Summary

Gracias por el reporte. `dev` confirma una regresión: el webhook sólo frena la cancelación si la línea ya estaba enrolada, aunque el flujo manual actual puede enrolar candidatos después.

## What This Changes

Impedir que el webhook de Exotec cancele pedidos con una línea `NOT_FOUND` elegible para la segunda pasada Skypod antes de GENERAR NE/S.

## Best Possible Solution

Usar la condición de candidato antes de buscar sustitutos, mantener intactas las ramas B2B y no candidatas, y cubrir que el endpoint manual pueda crear la NE-EX posteriormente.
