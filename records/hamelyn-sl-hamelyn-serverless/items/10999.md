## Summary

La propuesta cubre el prefijo catalán, pero la revisión de Asamblea señala dos fallos funcionales todavía visibles en el HEAD: la búsqueda interactiva pierde el mercado y varios enlaces del footer abandonan el prefijo delegado. Mantener abierto hasta resolverlos.

## What This Changes

El PR delega `/cat/comprar/:path*` al storefront ecommerce, añade routing consciente del mercado y cambia los redirects del resto de prefijos para llevarlos a sus dominios de tienda.

## Best Possible Solution

Mantener los enlaces internos y las peticiones de catálogo dentro del contexto de mercado delegado, sin cambiar el comportamiento de los despliegues existentes que no tengan la variable activada.

## Maintainer Decision

Required: false

## Reproduction Assessment

Sí: la ruta del proxy excluye `/api`, mientras que la búsqueda usa `/api/v5/products/search`; el footer construye enlaces con la URL base del locale catalán. Asamblea documenta ambos escenarios concretos.

## Solution Assessment

La delegación por prefijo es coherente con el objetivo descrito, pero el cambio necesita conservar el contexto de mercado también en las consultas API y enlaces del footer para completar el flujo.
