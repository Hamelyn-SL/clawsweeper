## Summary

La selección explícita es útil, pero esta rama rompe el arranque de checkouts existentes que solo configuran `MONGO_URL`; no debe mergearse hasta definir una transición y el valor por defecto seguro.

## What This Changes

La rama añade `--db=prod|dev` a `dev:run`, crea `local:run` y centraliza la selección de Mongo mediante `MONGO_URL_PROD` y `MONGO_URL_DEV`.

## Best Possible Solution

Mantener el selector visible, conservar temporalmente el comportamiento heredado o ejecutar una migración explícita y verificable antes de hacer obligatorias las variables raíz nombradas.
