## Summary

El caso de `REPORT_INACTIVE` sigue fuera del selector: la cola admite `ACTIVE`, espejos sin estado vendidos recientemente y, solo en Amazon ES, `REPORT_EXCESS_QUANTITY`. El contexto documenta una cancelación y casos análogos; las soluciones relacionadas no cubren este estado.

## What This Changes

Solicita que la retirada de Amazon envíe DELETE también a espejos `INACTIVE` con `REPORT_INACTIVE` cuando se vende el stock.

## Best Possible Solution

Definir un criterio acotado para seleccionar espejos vendidos `INACTIVE` con `REPORT_INACTIVE` y validar el alcance regional y el coste antes de desplegarlo.
