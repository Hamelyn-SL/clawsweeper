## Summary

La corrección sigue siendo necesaria en `dev`: el flujo actual convierte un lookup vacío en `gone` tras cualquier error inicial. Hay una PR abierta que declara resolver exactamente este caso, así que esta issue debe permanecer abierta hasta que se integre.

## What This Changes

Impedir que fallos HTTP ambiguos al retirar una oferta eBay se clasifiquen como `gone` y borren el mirror reintentable.

## Best Possible Solution

Revisar e integrar https://github.com/Hamelyn-SL/hamelyn-serverless/pull/9167, manteniendo `gone` reservado para ausencia confirmada y planificando aparte la revisión segura de los mirrors ya tombstoneados.
