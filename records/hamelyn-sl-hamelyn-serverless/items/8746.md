## Label Justifications

- `P1`: Un solo producto con una descripción inválida puede bloquear repetidamente la creación de todos los stocks válidos de un lote Fnac.
- `impact:other`: El impacto concreto es un fallo masivo del flujo de publicación de marketplace, fuera de las clases específicas de impacto disponibles.

## Summary

La incidencia sigue siendo necesaria: el formateador actual permite controles XML inválidos y puede generar un surrogate aislado antes de construir un único XML para todo el lote.

## What This Changes

Corregir el formateo de descripciones de Fnac para eliminar caracteres inválidos y evitar truncados UTF-16 que rompan el XML de create.

## Best Possible Solution

Sanear la descripción exclusivamente en la integración Fnac antes de serializar XML, con truncado seguro por puntos de código y regresiones que prueben tanto el XML como el lote afectado.

## Maintainer Decision

Required: false

## Reproduction Assessment

Sí, por fuente: una descripción con `U+000F` llega al `Builder` sin saneamiento y su excepción entra en la ruta que marca el lote como error. No se ejecutó una prueba local por el contrato de revisión de solo lectura.

## Solution Assessment

Sí. Un saneamiento local a Fnac antes del XML, junto con un truncado seguro por puntos de código, elimina la causa sin cambiar el comportamiento compartido de otros marketplaces.
