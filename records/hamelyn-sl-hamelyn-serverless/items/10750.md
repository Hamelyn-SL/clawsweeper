## Summary

Gracias por el contexto. La PR aborda una ruta que sigue emitiendo `console.error` en `processEbayOrders`; el cambio previo para retirar errores de ciertas retiradas no confirmadas no cubre esta firma concreta. No hay base para cerrar como ya implementada.

## What This Changes

La PR conserva la oferta en `EbayWithdrawalUnconfirmedError` y rebaja a `info` el log de retiradas eBay aceptadas cuya lectura inmediata sigue mostrando `PUBLISHED/OUT_OF_STOCK` para el mismo SKU sin retención.

## Best Possible Solution

Mantener la retirada sin confirmar como tal, pero registrar a nivel informativo únicamente la combinación validada de POST aceptado, estado `PUBLISHED/OUT_OF_STOCK`, SKU y marketplace coincidentes y ausencia de retención; conservar `error` para los demás fallos.
