Gracias por el contexto: el PR que delegó la ruta catalana ya está integrado, pero la configuración actual sigue apuntando a `ecom`; el fallo descrito depende además de cómo Vercel aplica el grupo a sus dominios, así que no hay evidencia para darlo por resuelto en el código.

## What This Changes

## Best Possible Solution

Mantener `ecom` asociado a `tienda.hamelyn.com`, delegar `/cat/comprar` a un proyecto separado sin dominios públicos propios y demostrar que el build de `supply-next` y ambos dominios funcionan tras el cambio.
