## Summary

La migración sigue siendo necesaria: eBay ES continúa en el orquestador legacy y la base V2 solo compone Discogs. La dependencia genérica ya está integrada, pero falta decidir y materializar la fase LMS sin competir con la reconciliación existente.

## What This Changes

Migrar la sincronización de eBay ES a `MarketplaceManager` V2, preservando la reconciliación LMS y la convivencia controlada con el flujo legacy.

## Best Possible Solution

Añadir el adapter y la ruta V2 de eBay con una fase LMS específica bajo el mismo lock, mantener V1 como fallback manual y efectuar el switchover solo tras validar API viva, ticks locales e índices Atlas.
