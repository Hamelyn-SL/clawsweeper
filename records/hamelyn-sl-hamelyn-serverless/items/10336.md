## Summary

Mantendría este PR abierto: es la propuesta enlazada a la incidencia aún abierta y corrige el coste usado en factura, pero el cálculo de media puede dejar nuevas unidades a 0 si falla la consulta; además, queda por confirmar el criterio contable de imputación anual.

## What This Changes

Cambia las facturas agrupadas MELI para usar `stocks.priceBuy` y asigna a nuevos stocks sin precio pagado una media anual de costes existentes.

## Best Possible Solution

Mantener la valoración de factura basada en el coste congelado del stock, y evitar persistir unidades sin coste estimado; confirmar también el criterio contable de imputación anual antes de consolidarlo.
