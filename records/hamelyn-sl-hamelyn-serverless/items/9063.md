## Summary

La incidencia sigue siendo necesaria: Feltrinelli clasifica correctamente el HTTP 429, pero su ruta V2 no tiene una cuota de escritura ni un freno compartido confirmado. Hace falta decidir el límite OF24 antes de implementar una reserva segura.

## What This Changes

La incidencia solicita evitar respuestas HTTP 429 repetidas al crear ofertas de Feltrinelli desde `/api/feltrinelliV2`.

## Best Possible Solution

Medir la cuota OF24 de Feltrinelli y aplicar una reserva compartida conservadora antes de cada POST, con pruebas para creación, retirada y precio.
