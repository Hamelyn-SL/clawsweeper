## Summary

Gracias por el reporte: la integración actual crea las publicaciones argentinas con 20 días, así que el cambio para nuevas publicaciones sigue pendiente. La actualización masiva de las ya publicadas requiere además concretar una operación con Mercado Libre; no hay comentarios que indiquen que ya se haya ejecutado.

## What This Changes

Solicita reducir de 20 a 15 días el tiempo de disponibilidad de publicaciones de Mercado Libre Argentina, tanto nuevas como ya existentes.

## Best Possible Solution

Ajustar la configuración de MLA para las nuevas publicaciones y definir una actualización controlada mediante la API de Mercado Libre para las ya publicadas, verificando límites y resultado antes de aplicar cambios masivos.
