## Summary

Mantener abierto: un `orderSell` sin `orderId` puede reintentarse primero cada hora y frenar los envíos posteriores durante hasta cuatro días; además, la prueba aportada sigue siendo simulada.

## What This Changes

El PR migra el procesamiento y la confirmación de envíos de Alibris a `MarketplaceManager` V2, redirige el cron horario y comparte un lock con la ruta legacy.

## Best Possible Solution

Conservar el error para el pedido sin identificador, pero hacerlo no reintentable o excluirlo de la selección de envío para que las ventas válidas sigan generando su `.STA`.

## Solution Assessment

No: conservar el `SYNC_ERROR` es correcto, pero debe impedirse su reintento automático para no bloquear la cola de confirmaciones.
