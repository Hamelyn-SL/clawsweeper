## Summary

La incidencia sigue siendo necesaria: el flujo actual de Revisión V3 exige registrar defectos y deriva el estado desde esa selección; no existe un panel turbo ni una traza que identifique revisiones aceleradas. Requiere validar la dirección de producto antes de implementar.

## What This Changes

La solicitud propone un panel independiente de revisión turbo para lotes B2C que marque cada producto escaneado como Muy Bueno, mida productos por minuto y conserve trazabilidad separada.

## Best Possible Solution

Crear un flujo y una entrada de Admin separados que reutilicen las transiciones B2C de Revisión V3, persistan explícitamente el modo turbo y registren productividad sin mezclar sus métricas con la revisión normal.
