## Label Justifications

- `P1`: Puede cancelar varios pedidos de clientes durante una caída temporal de un proveedor de dropshipping.
- `impact:other`: El impacto concreto es una decisión operativa irreversible sobre pedidos, fuera de las clases más específicas disponibles.

## Summary

La incidencia sigue siendo necesaria: el cron de tracking cancela inmediatamente cualquier error codificado de Azeta o Arnoia, aunque la política compartida solo considera explícitos algunos rechazos.

## What This Changes

La issue solicita que los errores transitorios con código de Azeta o Arnoia sigan el reintento de tracking en vez de cancelar el pedido inmediatamente.

## Best Possible Solution

Hacer que tracking comparta una única clasificación de rechazo explícito, conservando la ventana de 168 horas para fallos transitorios o desconocidos y añadiendo cobertura de la forma real de error.
