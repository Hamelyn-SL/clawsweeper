## Summary

Gracias por el contexto: el flujo actual aún demota los SKU `DB_ONLY` sin consultar Listings Items, y la evidencia aportada muestra dos casos MX que seguían `BUYABLE`. El PR fusionado que corrigió otra firma no cubre esta ausencia real del export.

## What This Changes

Añadir una comprobación remota antes de que el report de Amazon MX marque como `INACTIVE` listings que no aparecen en el export.

## Best Possible Solution

Antes de demotar un SKU ausente del export MX, consultar Listings Items y conservar el estado cuando el resultado sea `BUYABLE` o ambiguo; mutar solo con una ausencia o estado no comprable confirmado y añadir regresión para ambos resultados.
