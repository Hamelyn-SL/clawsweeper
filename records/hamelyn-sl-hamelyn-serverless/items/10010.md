## Summary

Gracias por la aclaración de almacén: el comportamiento solicitado sigue sin estar implementado. El flujo actual permite FedEx desde Spring o SEUR, pero bloquea regenerar el envío si el pedido ya tiene tracking FedEx.

## What This Changes

## Best Possible Solution

Añadir una ruta FedEx → FedEx de 2–30 bultos que regenere la expedición y sustituya tracking y etiquetas solo tras validar el tracking existente y completar correctamente la nueva generación.
