## Summary

El código actual confirma el fallo descrito: con una URL terminada en `/`, la clave incluye la barra y el recargo configurado no se encuentra. La regresión afecta precios visibles en producción, así que este issue debe seguir abierto hasta corregirla.

**Personas probablemente relacionadas:** Miguel Angel Hernández Perdomo, por los cambios recientes de resolución del site.

## What This Changes

El issue solicita que la sobretarifa regional se resuelva correctamente con URLs de site con o sin barra final, conservando los casos especiales y el fallback actuales.

## Best Possible Solution

Normalizar el host del base URL antes de extraer el TLD, mantener el caso especial de EE. UU. y el fallback, y añadir regresiones para URLs con y sin barra y dominios como `loja.hamelyn.com.br`.
