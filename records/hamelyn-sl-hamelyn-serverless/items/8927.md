## Label Justifications

## Summary

La petición sigue siendo necesaria: `PreparationView` mantiene una composición exclusiva para una gaveta unitaria y solo muestra `SameBinList` al entrar en modo múltiple. Falta la referencia visual acordada para cerrar el alcance con seguridad.

## What This Changes

Unificar la preparación de Station para renderizar siempre la cola multiproducto, también cuando la gaveta solo tiene un producto.

## Best Possible Solution

Acordar una referencia visual y la resolución de Station; después retirar la rama individual, adaptar `SameBinList` al caso unitario y validar el flujo completo en el puesto real.
