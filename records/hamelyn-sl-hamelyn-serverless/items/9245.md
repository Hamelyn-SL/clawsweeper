## Summary

Se mantiene abierto: el parche aborda un defecto activo, pero deja una sustitución encadenada inválida, permite una carrera que duplica operaciones de picking y adopta una semántica contable aún pendiente de decisión.

## What This Changes

El PR unifica las cuatro rutas de sustitución de picking en un servicio transaccional que repunta el pedido, conserva `replacedProducts` y reclasifica la unidad original como `INVENTORIED`.

## Best Possible Solution

Acordar la razón contable del original y, después, comparar la alternativa con la SKU localizada y reclamar atómicamente el enrutado antes de crear una operación de picking.
