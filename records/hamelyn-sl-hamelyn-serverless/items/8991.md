## Summary

La incidencia sigue siendo necesaria: el código actual pierde el detalle de algunos rechazos de eBay y el recovery vuelve a encolar los `SYNC_ERROR` que no coinciden con las firmas terminales de Amazon. La PR vinculada está abierta y solo cubre el diagnóstico inicial.

## What This Changes

Conservar el motivo saneado de los errores de confirmación de envío de eBay y evitar reintentos indefinidos cuando el rechazo sea permanentemente no recuperable.

## Best Possible Solution

Fusionar la mejora de diagnóstico, observar una firma eBay saneada en un rechazo real y extender la lista terminal únicamente para esa causa confirmada en los recoveries aplicables.

Owner confidence: high

Options:

- **Añadir firmas confirmadas (recommended):** Fusionar el diagnóstico y añadir al patrón terminal solo los `errorId/message` que eBay confirme como no recuperables.
- **Mantener todos los 400 reintentables:** Conservar el recovery actual hasta disponer de más muestras, aceptando reintentos adicionales en casos permanentes.

## Reproduction Assessment

Sí, por código y telemetría aportada: un `SYNC_ERROR` de eBay sin coincidencia terminal vuelve a `PENDING` en el recovery horario. No se ejecutó el cron contra datos de producción durante esta revisión.

## Solution Assessment

Sí para el primer paso: la PR abierta preserva el diagnóstico mínimo sin relajar el schema global. La exclusión terminal debe basarse después en una firma eBay observada y confirmada.
