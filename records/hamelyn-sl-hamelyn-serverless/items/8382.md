## Summary

La issue sigue siendo necesaria en `dev`: el parser activa cualquier fila con `Quantity > 0` y la reconciliación reactiva todos los `MK_ONLY` sin evidencia viva. La PR vinculada https://github.com/Hamelyn-SL/hamelyn-serverless/pull/8513 sigue abierta y declara resolver este flujo.

## What This Changes

Añadir estado vivo de oferta y señales `LISTING_ON_HOLD` al snapshot eBay ES para impedir decisiones y reactivaciones basadas solo en el LMS.

## Best Possible Solution

Revisar e integrar la PR vinculada tras fijar una política operativa explícita para cuándo los avisos `LISTING_ON_HOLD` bloquean mutaciones, manteniendo el contador como diagnóstico.

Options:

## Solution Assessment
