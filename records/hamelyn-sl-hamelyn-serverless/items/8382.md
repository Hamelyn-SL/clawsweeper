## Summary

La issue sigue siendo necesaria en `dev`: el parser considera activo cualquier `Quantity > 0` y la reconciliación reactiva todos los `MK_ONLY`. La PR abierta https://github.com/Hamelyn-SL/hamelyn-serverless/pull/8513 declara resolverla, así que debe permanecer abierta hasta su revisión e integración.

## What This Changes

Corregir la reconciliación del snapshot eBay ES para clasificar los `MK_ONLY` con Inventory API, evitar reactivaciones de ofertas no publicadas y registrar exclusiones `LISTING_ON_HOLD`.

## Best Possible Solution

Revisar e integrar la PR enlazada tras fijar una política fail-closed medible para `LISTING_ON_HOLD` y comprobar el primer run productivo con los nuevos campos de BigQuery.
