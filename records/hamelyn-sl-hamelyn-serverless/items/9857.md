## Summary

Gracias por el diagnóstico y las comprobaciones: el fallo sigue confirmado en rutas dinámicas; el código actual conserva `cacheComponents` y ejecuta `notFound()` dentro de las páginas, mientras el proxy devuelve 404 temprano solo si no encuentra una ruta.

## What This Changes

La issue solicita que las rutas dinámicas inexistentes respondan HTTP 404 real en vez de devolver 200 con la página de error renderizada.

## Best Possible Solution

Resolver la existencia y elegibilidad de producto, categoría y autor antes de que empiece el streaming, manteniendo los casos válidos, aliases y reglas de paginación.
