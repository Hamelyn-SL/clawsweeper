## Summary

Este PR sigue siendo necesario, pero no está listo para integrar: la rama mantiene bypasses en protecciones de ramas, el gate de CI puede omitir parte de lo que promete auditar y hay una solicitud humana de cambios pendiente. Además falta evidencia real posterior al cambio.

## What This Changes

La rama añade hooks y un workflow de convenciones, reorganiza el catálogo compartido de skills y modifica automatizaciones de Fallow, Dependabot y Skill Guardian.

## Best Possible Solution

Alinear los guards con las prohibiciones absolutas, completar las comprobaciones de CI, atender los comentarios de revisión y acordar una transición explícita para las skills retiradas antes de integrar.
