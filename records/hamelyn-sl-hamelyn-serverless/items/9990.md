## Summary

La fase sigue siendo necesaria: core ya concentra parte del envío, pero persisten consumidores y reglas repartidos cuya equivalencia aún no está inventariada ni extraída tras una fachada común.

## What This Changes

La issue pide inventariar los flujos de comunicación existentes y extraer los envíos de email al módulo compartido de core sin cambiar todavía proveedores ni canales no-email.

## Best Possible Solution

Completar primero una matriz verificable de cada familia y migrarlas gradualmente a una fachada de core con pruebas de equivalencia de payload, marcas y número de invocaciones.
