## Label Justifications

- `P2`: El informe mide cancelaciones y ventas cruzadas en un subconjunto de pedidos, con impacto operativo real pero sin evidencia de una caída general del servicio.
- `impact:other`: La inconsistencia de inventario entre canales y las cancelaciones resultantes tienen impacto concreto fuera de las categorías específicas disponibles.

## Summary

Gracias por el análisis y por el contexto de la telemetría. El código aún consulta solo pedidos pagados, y la triage confirma que falta definir cuándo reservar y liberar el stock; no hay base para cerrar esta issue ni para importar impagados directamente al flujo de preparación.

## What This Changes

Se solicita evitar ventas cruzadas reservando el stock desde la compra pendiente de pago en TodoColección, con una liberación definida si el pedido se cancela o no se paga.

## Best Possible Solution

Representar el pedido impagado como reserva de inventario, separada de preparación y venta confirmada, y liberar esa reserva de forma idempotente ante el evento o plazo que defina el equipo.
