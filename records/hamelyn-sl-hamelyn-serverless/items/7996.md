Mantener abierta: `dev` ya elimina el marcador sticky, pero la eliminación genérica de comentarios HTML también borra notas de usuario, incumpliendo el requisito explícito de preservarlas.

## What This Changes

La issue pide limpiar los marcadores internos de PR Proof del cuerpo de una PR sin eliminar comentarios HTML escritos por el usuario.

## Best Possible Solution

Sustituir la eliminación genérica por una lista explícita de marcadores internos y añadir una regresión que conserve `<!-- user-note -->`.
