## Summary

Gracias por el detalle: el código actual sigue enviando el heartbeat como `mode: "task"`, mientras que el comportamiento descrito requiere que la sesión sobreviva al turno del agente delegado. No hay un PR abierto que cubra este cambio.

## What This Changes

El reporte solicita que los heartbeats de watchers puedan delegar trabajo y, aun así, esperar a emitir sus métricas antes de finalizar.

## Best Possible Solution

Ajustar el modo de las sesiones heartbeat para que las notificaciones de tareas delegadas puedan reanudarlas y verificar que cada ciclo emita sus métricas sin habilitar solicitudes de entrada.
