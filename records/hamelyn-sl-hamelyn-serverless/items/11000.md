## Summary

Gracias por el contexto: el backend registra y elimina tokens FCM, pero aún no sincroniza instalaciones con WonderPush. La compatibilidad y el contrato de baja siguen pendientes según la aceptación y el comentario de triage, así que esta funcionalidad no está lista para cerrarse ni para implementarse con seguridad.

## What This Changes

La issue propone sincronizar con WonderPush los tokens push FCM y el `userId` al registrarlos, darlos de baja al eliminarlos y mantener el registro local aunque falle el proveedor.

## Best Possible Solution

Mantener una única fuente de tokens FCM en la app y añadir sincronización de servidor con WonderPush solo cuando el proveedor confirme el contrato para iOS, la asociación de usuario, la actualización continua y la baja.
