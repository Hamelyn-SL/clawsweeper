  - body: `--queue` promete registrar sin enviar, pero una publicación normal sincroniza toda la outbox y transmite también trabajos previos. Limita la sincronización al `request_id` creado o deja el drenado completo para `sync`.

  - body: Un claim omitido por `valid_from` puede activarse antes del último lote, pero solo se revalidan IDs ya guardados. La respuesta `complete: true` puede publicar un complemento incompleto hasta otra pasada completa.
  - confidence: 0.94

  - body: `text()` acepta 4.000 caracteres, pero el servidor rechaza cuerpos JSON de más de 16.000 bytes. Un extracto válido con caracteres UTF-8 de cuatro bytes no puede autorizarse; valida bytes al borde o amplía el transporte.
  - confidence: 0.96
