## Summary

Gracias por el contexto: los datos comentados confirman que el lote se recibió, pero `main` aún deriva la etiqueta de cabecera del estado de origen. El PR abierto propone corregir esa diferencia y mantiene este trabajo pendiente de resolución.

## What This Changes

La incidencia pide que, al completar la recepción de un lote que estaba «Pendiente de recoger», la cabecera indique que está recibido, igual que en una recepción normal.

## Best Possible Solution

Mantener el estado de origen para avisos y acciones, pero mostrar la etiqueta de cabecera «RECIBIDO» cuando se complete en esta visita la recepción automática de todos los bultos.

## Solution Assessment

Sí; cambiar solo la etiqueta al completar la recepción conserva la lógica existente y evita alterar el estado de origen usado por avisos y acciones.
