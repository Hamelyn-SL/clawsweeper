## What This Changes

Se solicita acreditar proporcionalmente los artículos de un lote según los bultos recibidos cuando se declara una incidencia por bultos faltantes.

## Best Possible Solution

Si Operaciones confirma el reparto, registrar el crédito parcial y el saldo pendiente de forma que cada artículo se atribuya una sola vez al operario que corresponda cuando lleguen los bultos restantes.
