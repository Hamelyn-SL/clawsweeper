## Summary

La incidencia sigue siendo necesaria: `dev` no reconoce `101078`, por lo que un error mixto con códigos de precio puede clasificarse como `TRANSIENT` y alcanzar rutas de recovery.

## What This Changes

Impedir el recovery automático de listings Amazon con `101078` y definir una remediación regional segura para condiciones inconsistentes entre marketplaces.

## Best Possible Solution

Añadir primero un guard explícito `101078 → UNKNOWN` con exclusión en recovery y, por separado, diseñar el resolver account-wide con preflight, preview y aprobación antes de cualquier backfill.
