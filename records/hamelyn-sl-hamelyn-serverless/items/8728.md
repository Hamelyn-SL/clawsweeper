## Summary

La mejora sigue siendo necesaria: el escaneo aún depende de una segunda petición del navegador para encolar lotes completos. Gracias por el diagnóstico previo; confirma una separación real entre el marcado y el encolado que puede dejar trabajo listo sin disparar.

## What This Changes

Automatizar el encolado de lotes `REVIEWED` completamente escaneados al marcar una gaveta, manteniendo `validate` como reintento manual idempotente.

## Best Possible Solution

Extraer un servicio servidor compartido que marque, calcule elegibilidad y encole; devolver un resultado por lote y gavetas bloqueantes, dejando `validate` como reintento idempotente.
