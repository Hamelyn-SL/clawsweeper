## Summary

La firma corresponde con alta probabilidad a respuestas 429 de MercadoLibre durante escrituras POST; el cliente las registra y propaga sin reintentos, por lo que este issue sigue siendo necesario.

## What This Changes

Evitar que el cron de MercadoLibre MX repita fallos de escritura registrados como `AxiosHeaders` y complete sus ejecuciones.

## Best Possible Solution

Añadir al POST el mismo reintento acotado para 429 que ya usa PUT, respetando `Retry-After`, y cubrir tanto la recuperación como el agotamiento de reintentos.
