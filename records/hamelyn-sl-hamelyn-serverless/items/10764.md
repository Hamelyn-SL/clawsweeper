## Label Justifications

- `P1`: La numeración duplicada puede asociar containers de operaciones distintas en el flujo de packing.

## Summary

El hallazgo previo sigue presente: la inicialización toma el sufijo del container (`--n`), no el número de operación `NE-EX-n`; puede sembrar el contador por debajo de operaciones existentes y volver a asignar nombres ya usados.

## What This Changes

El PR añade un contador KV atómico por picking para reservar secuencias NE-EX y adapta el planificador para reservar bloques consecutivos.

## Best Possible Solution

Sembrar el contador desde el número de operación NE-EX más alto ya existente para ese picking y conservar la reserva atómica de bloques; añadir cobertura para operaciones con varios containers y secuencias no consecutivas.

## Maintainer Decision

Required: false

## Reproduction Assessment

Sí: con una operación existente `NE-EX-7--1`, la extracción propuesta obtiene 1 y permite reservar una secuencia inferior a la ya usada.

## Solution Assessment

No todavía: el contador atómico es una vía adecuada, pero su semilla debe extraer el número de operación y no el ordinal final del container.
