## Label Justifications

- `P1`: Una colisión en la secuencia puede asociar operaciones de picking distintas a nombres y containers repetidos en el flujo de almacén.
- `merge-risk: 🚨 message-delivery`: Una secuencia reutilizada puede dirigir productos de operaciones distintas a containers con identificadores compartidos.

## Summary

El cambio aborda una colisión operativa documentada, pero el cálculo de inicialización toma el último componente de `container`, que es el índice local 1–15 y no la secuencia `NE-EX-n`; así, tras una operación con secuencia superior a 15, puede volver a reservar un número ya usado. La evidencia de prueba también limita la atomicidad al simulador KV, no a un servicio KV real.

## What This Changes

Añade un contador KV atómico por picking para asignar bloques de secuencias NE-EX y ajusta el planificador para reservarlos de una vez.

## Best Possible Solution

Inicializar el contador extrayendo el número `NE-EX-n` de cada nombre de container y tomando el máximo por picking, con cobertura para secuencias mayores de 15, prefijos `M-`/`BL` y contenedores históricos; confirmar además `SET NX` e `INCRBY` contra el proveedor KV.

## Solution Assessment

No todavía: el contador atómico es una solución adecuada para la concurrencia, pero la inicialización debe recuperar la secuencia del nombre `NE-EX-n`, no el ordinal local del container.
