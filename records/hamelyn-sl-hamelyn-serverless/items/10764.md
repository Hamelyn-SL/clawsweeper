## Summary

El cambio aborda el problema de numeración, pero sigue sembrando el contador con el índice del container y no con el número de operación; una NE-EX-10--15, por ejemplo, puede iniciar el contador en 15. El defecto ya se señaló en la revisión anterior y continúa en el head actual.

## What This Changes

El PR reserva bloques de números NE-EX mediante un contador KV atómico por picking y adapta el planificador para solicitar los bloques necesarios.

## Best Possible Solution

Sembrar el contador desde el número de operación extraído del formato NE-EX y añadir cobertura para operaciones de varios bloques, como NE-EX-10--15 y NE-EX-11--1.

## Maintainer Decision

Required: false

## Reproduction Assessment

Sí: el formato probado NE-EX-10--15 permite verificar por inspección que el segmento final es el índice del container, no el número NE-EX.

## Solution Assessment

No del todo: la reserva atómica por picking es adecuada, pero su siembra debe extraer el número de operación y probar expresamente el formato de múltiples bloques.
