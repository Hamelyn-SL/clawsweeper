## Summary

El objetivo es válido, pero el parche deja tres caminos de deduplicación que pueden crear incidencias duplicadas o perder evidencia de una variante recién observada.

## What This Changes

El PR agrupa incidencias de Amazon, Mirakl y FNAC por causa compartida, conserva observaciones por ruta y hace que un fallo de búsqueda de GitHub bloquee la creación.

## Best Possible Solution

Mantener la agrupación conservadora, pero reutilizar canónicas cerradas, consolidar evidencia durante la reapertura y estabilizar solo las coordenadas de stack relevantes.
