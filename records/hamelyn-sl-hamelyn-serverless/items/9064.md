## Summary

La incidencia sigue siendo necesaria: el código actual detecta una ausencia real de `product.image`, pero continúa enviando `main_image`, y TodoColección puede publicar el anuncio sin foto. Hace falta decidir la política de publicación y reintento.

## What This Changes

Evitar que `/api/todoColeccionV2` publique listings cuando el producto carece de metadatos de imagen.

## Best Possible Solution

No publicar listings sin imagen válida y conservar una vía explícita para reintentarlos cuando el enriquecimiento de catálogo aporte la imagen.

Sí, por código: cualquier `findProductByEan` que devuelva un producto sin `image` activa el aviso y el formatter aún construye el payload de creación.

## Solution Assessment

No, silenciar el aviso no resuelve la publicación degradada; la solución debe definir retención o publicación y el reintento posterior a enriquecimiento.
