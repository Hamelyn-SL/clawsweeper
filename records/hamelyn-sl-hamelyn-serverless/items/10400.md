## Summary

La protección propuesta evita degradaciones para los SKU comprobados, pero el límite deja el resto en la ruta antigua, que los pone en `INACTIVE` sin consultar Amazon. Como esto conserva el riesgo central y la issue vinculada sigue abierta, el PR necesita una corrección acotada antes de cerrar el ciclo.

## What This Changes

El PR consulta Listings Items antes de degradar SKU `DB_ONLY`, conserva los casos comprables o no confirmados, limita las comprobaciones a 200 por región y añade tests y logs.

## Best Possible Solution

Mantener la verificación previa a la degradación para todos los SKU: si la cuota impide comprobar el exceso, conservarlos activos y dejar constancia para una comprobación posterior, en vez de aplicarles la degradación heredada.
