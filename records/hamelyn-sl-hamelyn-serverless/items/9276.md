## Summary

El PR sigue siendo necesario para la incidencia enlazada, pero no es seguro fusionarlo aún: la nueva excepción `noRetry` permite que una corrección de gaveta fallida deje pasar el cierre del lote como si hubiera persistido.

## What This Changes

El PR añade criterio de calidad por lote en Turbo Revisión, permite reasignar gavetas desde el historial y reinicia el estado de gaveta y criterio entre sesiones de productividad.

## Best Possible Solution

Conservar la serialización por unidad, pero hacer que cualquier corrección interactiva no confirmada bloquee el cierre y que cada reintento actualice la cadena `drawer:<unitId>`.
