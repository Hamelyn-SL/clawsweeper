## Summary

Este PR sigue siendo necesario para la mejora de Turbo Revisión, pero no es seguro fusionarlo aún: quedan tres rutas de persistencia que pueden desalinear la gaveta mostrada, la Order y el Stock.

## What This Changes

Añade un criterio de calidad por lote en Turbo Revisión, permite mover gavetas desde el historial y limpia el estado local de gaveta y calidad al cambiar sesiones de productividad.

## Best Possible Solution

Mantener una única cadena autoritativa por unidad, bloquear el cierre ante cualquier asignación final fallida y sincronizar transaccionalmente la gaveta del Stock enlazado o impedir el movimiento cuando ya exista.

## Solution Assessment
