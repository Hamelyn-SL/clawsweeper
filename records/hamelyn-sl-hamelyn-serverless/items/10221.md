## Summary

El cambio aborda el bloqueo de ejecución de Windows con una firma aislada del build y límites OIDC acotados. La prueba disponible confirma la lógica de publicación, pero aún no una firma real; además, la issue vinculada sigue abierta y esta rama es su propuesta de solución.

## What This Changes

Añade al workflow de publicación del CLI un job opcional para firmar y verificar `hamelyn.exe` con Azure Artifact Signing, y documenta la configuración necesaria.

## Best Possible Solution

Mantener la firma en un job aislado con OIDC de mínimo alcance y publicar el ejecutable firmado solo tras validar su firma; verificarlo en un release configurado antes de dar por resuelta la incidencia.
