## Summary

Gracias por el contexto: el flujo actual permite clasificar como sobrante un EAN ya revisado cuando está activo el destino automático. La confirmación solicitada añade una decisión operativa que aún debe validar el equipo; la issue relacionada cubre un caso más específico y no resuelve esta petición.

## What This Changes

Añadir avisos de confirmación en la revisión con destino automático para lecturas repetidas y artículos fuera del lote.

## Best Possible Solution

Definir una confirmación consistente en ambos hubs antes de registrar el sobrante, conservando la opción de continuar cuando el equipo la apruebe y sin afirmar que identifica el lote de origen.

Question: ¿Debe Revisión con destino automático pedir confirmación para EAN ya revisados y artículos fuera del lote, permitiendo continuar con la lectura si el operario confirma?

Rationale: El flujo actual interpreta artículos fuera del lote como posibles sobrantes y permite añadirlos; interrumpirlos o permitir continuar cambia el criterio operativo y puede afectar lecturas válidas de ejemplares adicionales.

Likely owner: banosdavidhamelyn

Owner confidence: medium

Options:

- **Avisar y permitir continuar (recommended):** Mostrar la confirmación en ambos hubs y registrar el ejemplar solo tras la confirmación del operario.
- **Avisar solo en lecturas repetidas:** Solicitar confirmación para EAN ya procesados y conservar el flujo actual para otros artículos fuera del lote.
- **Mantener el flujo actual:** No introducir confirmaciones hasta acordar otro control operativo para evitar sobrantes duplicados o cruzados.

## Reproduction Assessment

No aplica como reproducción de un fallo aislado: el código confirma que, con destino automático activo, el EAN revisado sigue la ruta de artículo fuera de lote y puede añadirse como sobrante.

## Solution Assessment

No está completamente decidido: una confirmación previa es viable, pero el equipo debe determinar si se aplica a toda lectura fuera de lote o solo a EAN ya revisados para no bloquear sobrantes legítimos.
