## Summary

Gracias por el contexto. La selección actual permite configurar reglas de envío por marketplace, código postal y número de unidades, pero no hay evidencia de una regla que envíe los pedidos estándar de Amazon de menos de 10 € a Madrid por Postlibri; los múltiples deben seguir por Cainiao.

## What This Changes

Añadir a la matriz una regla para pedidos estándar de Amazon de menos de 10 € con destino a códigos postales que empiecen por 28: Postlibri para una unidad y Cainiao para pedidos múltiples.

## Best Possible Solution

Confirmar con operaciones el umbral de precio, el patrón de envío estándar y el alcance de códigos postales, y aplicar reglas de matriz separadas para pedidos individuales y múltiples; mantener documentado que las etiquetas Postlibri siguen siendo manuales.
