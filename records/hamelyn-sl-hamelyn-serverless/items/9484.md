- `impact:other`: El impacto concreto es la ocupación prolongada y facturable de runners de GitHub Actions.

## Summary

La espera sigue activa en el flujo actual y resolverla bien exige escoger una arquitectura duradera que conserve ventanas, reintentos, métricas y alertas.

## What This Changes

La issue propone retirar de GitHub Actions la espera y el seguimiento de los watchers de marketplace, delegándolos a `apps/agents` o a runners dedicados.

## Best Possible Solution

Implementar un orquestador durable en `apps/agents` que registre solicitudes idempotentes, respete cada ventana y publique el resultado de métricas y alertas antes de retirar los jobs.
