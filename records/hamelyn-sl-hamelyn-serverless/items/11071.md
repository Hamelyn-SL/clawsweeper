## What This Changes

Spring recibe códigos HS de longitud impar para ciertos destinos y rechaza la etiqueta; el CSV de Spring también exporta el código nacional sin ajustar su longitud.

## Best Possible Solution

Integrar una única regla de formato par, de hasta 10 dígitos, en las salidas de Spring API y CSV, preservando el código nacional completo para factura y FedEx.
