## Summary

El PR cubre una necesidad real y aporta pruebas de uso, pero `startWorkIntervention` puede devolver una intervención abierta de otro tipo o proceso: el modal solicitado y la sesión que finalmente se cierra dejan de corresponder. Hace falta corregir ese cruce antes de integrar.

## What This Changes

Añade sub-sesiones para cambios de rollo y paletizado, ajusta el cálculo del panel de productividad, superpone esas sesiones en el cuadrante y registra códigos de bulto en etiquetas.

## Best Possible Solution

Mantener el modelo de intervenciones enlazadas al proceso padre y hacer que el servidor solo reutilice una sesión abierta cuando coincidan el tipo y el padre; si ya hay otra intervención activa, devolver un conflicto explícito.

## Solution Assessment

No del todo: las sub-sesiones encajan con la necesidad, pero la reutilización debe validar tipo y padre para evitar mezclar intervenciones.
