## Summary

El PR conserva una mejora útil, pero la concurrencia de cuatro suites hereda un heap de 6 GB por proceso y puede agotar el runner; debe corregirse antes del merge.

## What This Changes

El PR divide el gate monolítico de CI en trabajos paralelos, agrupa las suites de core y sustituye lecturas repetidas del guardian por `git cat-file --batch`.

## Best Possible Solution

Mantener la paralelización, pero acotar explícitamente la memoria por suite o reducir la concurrencia a un presupuesto seguro del runner, conservando el resumen agregado de fallos.
