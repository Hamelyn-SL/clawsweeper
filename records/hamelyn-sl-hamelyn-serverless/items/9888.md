## Summary

El criterio actual solo admite `Active` con cantidad `1`, por lo que la ruta descrita para cantidad `2` sigue presente en `main`; no hay un PR abierto que la resuelva. Personas relacionadas: MarcosTerroso (historial directo) y MiguelHamelyn (cambio previo de conciliación).

## What This Changes

Evitar que el report de Amazon ES aparque como `REPORT_INACTIVE` listings `BUYABLE` con cantidad `2`.

## Best Possible Solution

Ajustar el parser para reconocer cantidades enteras positivas como vendibles, conservar la prioridad de filas vendibles y las guardas de operaciones activas, y añadir cobertura para cantidades 0, 1 y 2 y estados remotos.
