## Summary

El PR corrige el provisional normal, pero introduce una regresión: las tarjetas `ML-I-` pierden permanentemente su etiqueta porque esa ruta nunca resuelve un contenedor alternativo. También deja vacías las tarjetas normales tras un fallo transitorio sin reintento.

## What This Changes

El PR limita el respaldo de `SameBinList` a contenedores clasificados como `BL`, ocultando el valor generado para el resto hasta recibir un contenedor resuelto.

## Best Possible Solution

Preservar los formatos cuyo contenedor generado ya es definitivo, incluido `ML-I-`, y diferenciar una resolución pendiente de un fallo reintentable antes de ocultar la etiqueta.
