## Label Justifications

- `P1`: Cada ejecución diaria de publicación revierte la flota completa, manteniendo los sitemaps SEO desactualizados mientras persista la caché.
- `impact:other`: El impacto concreto es la congelación de la indexación SEO de la tienda, que no encaja en las clases específicas de datos, sesión, mensajes o proveedor.

## Summary

La incidencia sigue siendo necesaria: el código actual trata una flota pública todavía cacheada como fallo definitivo y revierte `current.json`, sin esperar a que converja la nueva publicación.

## What This Changes

Evitar que el prewarm público de sitemaps haga rollback cuando las rutas canónicas aún sirven temporalmente la ejecución anterior desde caché.

## Best Possible Solution

Reintentar de forma acotada las URLs que devuelven consistentemente el run anterior, y revertir solo si no convergen dentro de un presupuesto que preserve el rollback seguro.

## Solution Assessment

Sí: un reintento acotado sobre el run previo es la vía más estrecha; invalidar caché sin conservar la distinción frente a fallos reales reduciría la seguridad del rollback.
