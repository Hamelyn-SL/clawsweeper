## Summary

La evidencia aportada y el código actual describen un hueco distinto de los casos anteriores: el anuncio sigue vendible, pero su mirror terminal queda fuera de la retirada ordinaria y la guarda del report no acepta esta secuencia de snapshots. La recuperación no está implementada para este caso.

## What This Changes

Evitar que un listing de Discogs permanezca vendible cuando el stock maestro y su mirror ya están retirados.

## Best Possible Solution

Ampliar la recuperación de huérfanos para este estado terminal solo tras validar por GET el ID y el SKU, con CAS sobre el mirror y el maestro, y comprobar la retirada y el siguiente snapshot correcto antes de escalar.
