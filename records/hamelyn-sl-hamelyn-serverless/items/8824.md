## Label Justifications

- `P1`: La retirada masiva de Amazon FR lleva fallando de forma recurrente y afecta a un flujo de Marketplace en producción.
- `merge-risk: 🚨 availability`: El control puede añadir una espera prolongada y todavía no evita la contención con otros envíos de feeds.

## Summary

Este PR reduce el pico dentro de una ejecución de retirada masiva, pero no coordina la cuota compartida con la actualización de precios; además, solo aporta una prueba simulada del helper.

## What This Changes

El PR incorpora una ventana local por `merchantId` que pausa la retirada masiva de Amazon tras cinco reservas de feed en cinco minutos.

## Best Possible Solution

Centralizar o compartir la coordinación de cuota para todos los productores de `JSON_LISTINGS_FEED` de una cuenta y validarla contra un entorno Amazon seguro.
