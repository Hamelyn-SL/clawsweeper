## Summary

Gracias por el reporte: el código de `dev` aún llama a la analítica al recibir el cambio de Stripe, y la PR vinculada sigue abierta. Mantener esta issue abierta hasta que se resuelva esa propuesta evita perder el seguimiento del fallo.

## What This Changes

Evitar que `add_shipping_info` y `add_payment_info` se envíen al montar el checkout antes de que el método de pago esté completo.

## Best Possible Solution

Conservar el registro del envío predeterminado y la deduplicación, pero emitir el evento de pago solo cuando Stripe indique que el método está completo; mantener la issue como seguimiento hasta que la PR vinculada se resuelva.
