## Summary

La incidencia sigue siendo necesaria: el código actual clasifica `NE-EX-` como `OTROS`, pero la estación impone `SKYPOD` antes de esa regla; falta decidir el ciclo seguro de sesión para corregirlo sin romper la atribución.

## What This Changes

La incidencia solicita que las revisiones `NE-EX-` de Skypod se registren como `OTROS` con detalle `NOT_FOUND`, sin contar tiempo ni artículos en `SKYPOD`.

## Best Possible Solution

Definir y aplicar un relevo atómico y acotado entre `SKYPOD` y `OTROS` para una `NE-EX`, conservando la validación de estación y verificando que no se registren artículos de Skypod.
