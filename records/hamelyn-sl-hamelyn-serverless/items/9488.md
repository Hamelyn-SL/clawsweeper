## Label Justifications

- `P1`: La discrepancia puede dejar cajas reales sin recoger en ventas activas, afectando una operación logística de clientes.
- `impact:other`: El impacto concreto es una recogida de transportista con un número de bultos distinto al pedido interno.

## Summary

Gracias por el contexto: la incidencia sigue siendo necesaria. `dev` corrige el cálculo interno de cajas, pero una fusión posterior al tracking solo persiste MongoDB y no sincroniza los bultos con MRW.

## What This Changes

Actualizar la recogida del transportista cuando una fusión de lotes aumenta el número de cajas tras haberse asignado tracking.

## Best Possible Solution

Definir una actualización MRW idempotente para fusiones con tracking, con respuesta persistida y una ruta operativa explícita cuando MRW rechace el cambio.

Rationale: El código dispone de una primitiva de modificación, pero falta decidir si se sincroniza, se bloquea la fusión o se deriva a una gestión manual cuando ya existe tracking.

Likely owner: HamelynDev

Owner reason: El historial y el triage reciente lo conectan con el flujo de merge y la integración MRW.

Owner confidence: high

Options:

- **Sincronización automática idempotente (recommended):** Modificar el envío MRW al fusionar, persistir el resultado y dejar el pedido pendiente de intervención si el transportista lo rechaza.
- **Bloquear la fusión con tracking:** Impedir que el cliente añada cajas cuando la recogida ya está contratada y mostrar una instrucción de soporte.
- **Gestión operativa manual:** Mantener la fusión interna y exigir a ATC que actualice cada recogida ya contratada antes de confirmarla.

## Reproduction Assessment

No con alta confianza: el código reproduce la ausencia de llamada a MRW tras guardar la fusión, pero falta un registro del transportista que confirme el rechazo o la actualización de bultos.

## Solution Assessment

No: añadir una llamada aislada no basta. Primero hay que acordar el comportamiento ante recogidas ya aceptadas y probar la modificación real de MRW, incluidos rechazos e idempotencia.
