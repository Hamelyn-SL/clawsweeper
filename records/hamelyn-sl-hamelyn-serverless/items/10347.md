## Summary

Gracias por el contexto. La impresión añade páginas de propósito distinto según la ruta: el marcador «FACTURA» sirve para emparejar paquete y factura, mientras que FedEx también tiene un tratamiento propio de copias AWB. Con el adjunto y la descripción no queda claro cuál se quiere suprimir, así que no hay base para cerrar ni para proponer un cambio concreto todavía.

## What This Changes

Se solicita evitar la impresión de páginas adicionales en las etiquetas de FedEx para pedidos de Mercado Libre Argentina.

## Best Possible Solution

Identificar la página concreta y delimitar la excepción a FedEx de Mercado Libre Argentina, conservando el marcador cuando siga siendo necesario para emparejar paquete y factura.
