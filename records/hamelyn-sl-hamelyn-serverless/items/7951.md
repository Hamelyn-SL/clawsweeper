## Summary

La incidencia sigue siendo necesaria: `dev` mantiene deliberadamente PR Proof como feedback no bloqueante, pero el éxito del despacho puede confundirse con un veredicto terminal fiable.

## What This Changes

Solicita que PR Proof espere un resultado terminal y publique evidencia trazable e inmutable vinculada al SHA y a cada ejecución.

## Best Possible Solution

Decidir y documentar si Proof seguirá siendo feedback no bloqueante; si es así, separar visualmente el acuse de despacho del resultado terminal para evitar que se lea como aprobación.
