## Summary

La issue sigue siendo necesaria: las superficies principales ya están integradas, pero una ficha válida terminada en `.md` aún devuelve HTTP 200 en producción y no hay un escaneo fresco que pruebe el 100/100 en ambos dominios.

## Best Possible Solution

Corregir el matcher para que una ficha real terminada en `.md` llegue al 404 Edge, volver a escanear ambos dominios y tratar cualquier ampliación del catálogo público como una decisión de API separada.
