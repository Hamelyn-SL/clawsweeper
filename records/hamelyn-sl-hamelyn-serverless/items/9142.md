## Summary

El PR sigue siendo necesario: `dev` aún prioriza el idioma desnormalizado del stock. El parche alinea el payload MX y su validación sin cambiar el flujo global; no encontré defectos concretos en el diff.

## What This Changes

El PR hace que las altas locales de MercadoLibre MX usen primero `product.attributes.language`, con fallback al idioma del stock, y documenta esa precedencia.

## Best Possible Solution

Integrar esta prevención para las nuevas altas y resolver por separado en la incidencia enlazada si procede una reconciliación controlada de fichas históricas.
