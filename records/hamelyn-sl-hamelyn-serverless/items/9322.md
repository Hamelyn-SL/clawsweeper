## Summary

El PR sigue siendo necesario para reducir el coste del cron, pero el gate no detecta un CP conflictivo oculto cuando el CP principal ya es válido; podría omitir Google para una dirección incoherente.

## What This Changes

El PR restringe la prevalidación proactiva de direcciones y evita la consulta a Google cuando las comprobaciones locales consideran sana la dirección.

## Best Possible Solution

Buscar CPs ocultos únicamente en municipio, provincia y línea de dirección, y conservar Google cuando alguno difiera del CP principal válido.

## Reproduction Assessment

## Solution Assessment
