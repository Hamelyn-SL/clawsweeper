## Summary

La incidencia sigue siendo necesaria: `dev` anuncia que el ✅ ejecutará antes de comprobar las desviaciones, aunque la misma ruta escala el pedido y la autorización posterior rechaza la ejecución automática.

## What This Changes

Corregir los avisos de cliente provisional para que, si el pedido B2B tiene desviaciones, indiquen que la ejecución requiere HITL con botones en lugar de prometer ejecución mediante ✅.

## Best Possible Solution

Calcular primero si el pedido puede autoejecutarse y emitir un aviso provisional condicionado; para desviaciones, señalar HITL y botones, conservando el texto actual solo para `awaiting_auth` sin anomalías.
