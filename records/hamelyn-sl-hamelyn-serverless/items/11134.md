## Summary

Gracias por el detalle: el código actual sigue aparcando filas clasificadas como `REPORT_INACTIVE`, y la evidencia describe una firma distinta de la ausencia `DB_ONLY` cubierta por el cambio anterior. La solución solicitada aún no está implementada en `dev`.

## What This Changes

Evitar que el report de Amazon MX aparque como `INACTIVE` y `REPORT_INACTIVE` tres listings confirmados recientemente como `BUYABLE` cuando la exportación contiene filas `Incomplete`.

## Best Possible Solution

Conservar `ACTIVE` cuando una fila `Incomplete` reciente contradiga una confirmación de oferta y verificar con Listings Items antes de aplicar `REPORT_INACTIVE`; mantener guards de concurrencia y no alterar ofertas ni precios.
