- `P1`: Un pedido con datos postales defectuosos puede bloquear la operación Postlibri completa y obligar a rehacer decenas de envíos.
- `impact:other`: El impacto principal es la interrupción operativa del lote de fulfillment, fuera de las categorías específicas de mensajes, sesión, auth o seguridad.

## Summary

Mantener abierta: `dev` aún genera `CP_Correos.txt` con el CP original y el literal `1`; la PR vinculada sigue abierta y no cubre el caso conocido `21030` de forma válida pero inexistente.

## What This Changes

Corregir la generación Postlibri para no bloquear lotes de Correos por CP inválidos, alinear el formato TXT y avisar operativamente de los pedidos excluidos.

## Best Possible Solution

Acordar un criterio de coherencia verificable para CP válidos en forma y completar una única partición que mantenga TXT, helper, sellado, correos y carga PDF en el mismo conjunto.
