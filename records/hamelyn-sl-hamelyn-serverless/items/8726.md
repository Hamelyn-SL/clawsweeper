## Repair Work Prompt

Implementa el gate de CP para el TXT Postlibri: conserva el valor original, valida formato español de cinco dígitos y coherencia con provincia, emite `CCCCC NNN` para los pedidos válidos y separa los excluidos. Asegura que los excluidos no entren en la expectativa de PDF ni provoquen el 409 de etiquetas faltantes; envía un aviso no bloqueante al canal de packing con pedido, motivo y enlace de admin. Añade cobertura de regresión para CP con letras, seis dígitos, `21030` con provincia incoherente, CP institucional válido y contador de tres cifras. No cambies el enrutado normal de Cainiao ni añadas scripts one-time; no se espera `CHANGELOG.md` para este arreglo.
