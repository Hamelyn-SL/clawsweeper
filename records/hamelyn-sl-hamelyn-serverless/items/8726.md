## Label Justifications

- `P1`: Un único pedido defectuoso puede bloquear la preparación diaria de un lote completo de Correos y forzar un cambio masivo de carrier.
- `impact:other`: El efecto comprobado es una interrupción operativa en la generación, subida y gestión de etiquetas de packing.

## Summary

Mantener abierta: `dev` aún genera el TXT con el CP original y marca todo el grupo como `POSTLIBRI`; la PR vinculada sigue abierta y declara que solo avisa, por lo que no evita el bloqueo del lote descrito.

## What This Changes

Evitar que un pedido Postlibri con dirección o código postal inválido invalide la subida completa a Correos, manteniendo el TXT y la carga de etiquetas coherentes.

## Best Possible Solution

Definir un resultado estructurado de elegible/excluido antes de sellar pedidos, usar la misma partición para TXT, `labelFile` y carga PDF, y acordar el tratamiento de CP formalmente válidos sin fuente fiable de existencia.
