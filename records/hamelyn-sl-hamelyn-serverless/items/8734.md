## Summary

El PR corrige el caso de listas explícitamente vacías, pero también cambia indebidamente a `0` los arrays no vacíos cuyos ranks no son numéricos; esa señal alimenta `formula_11`, así que no está listo para integrar sin el ajuste.

## What This Changes

El PR distingue listas vacías de `classificationRanks` de datos ausentes al calcular los conteos Amazon ES/COM y añade cobertura de regresión.

## Best Possible Solution

Devolver `0` únicamente para un array explícitamente vacío; conservar `null` si el array no contiene ningún rank numérico válido, con pruebas para ambos marketplaces y la semántica documentada.
