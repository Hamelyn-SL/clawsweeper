## Summary

El PR corrige un caso real de duplicados, pero el nuevo ack puede detener la única recuperación disponible cuando Exotec ya está `Inside` y los stocks siguen en `PENDING_SKYPOD`.

## What This Changes

El PR consulta el estado de declaración de Exotec y confirma sin reintentos los jobs duplicados cuando la cubeta está `Inside` con todos sus artículos declarados.

## Best Possible Solution

Confirmar el duplicado solo cuando no queden stocks pendientes que requieran activación, o mantener el reintento y la alerta hasta que el estado persistido se haya reconciliado.
