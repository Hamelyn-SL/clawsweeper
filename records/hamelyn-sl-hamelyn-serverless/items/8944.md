## Summary

La incidencia sigue siendo necesaria: `dev` aún aborta el dry-run de clientes no registrados y una PR abierta vinculada concentra el arreglo propuesto.

## What This Changes

Solicita que el watcher B2B publique el dry-run con un perfil provisional no ejecutable cuando el pedido no coincida con `B2B_CLIENTS`.

## Best Possible Solution

Integrar el perfil provisional solo para selección y publicación, con guardas explícitas en la reacción, la tool HITL y `executeOrder`, tras validar el flujo real y los clientes registrados.
