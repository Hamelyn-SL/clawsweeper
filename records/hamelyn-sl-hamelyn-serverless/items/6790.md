## Summary

La incidencia sigue siendo necesaria: `dev` aún permite retiradas genéricas con motivo `SOLD` o `SOLD_AS_ALTERNATIVE` sin guardar `soldAt`, y no existe una solución integrada para el histórico.

## What This Changes

Corregir las retiradas vendidas sin `soldAt`, recuperar el histórico mediante pedidos asociados y decidir la semántica de las sustituciones vendidas.

## Best Possible Solution

Separar una corrección acotada que complete `soldAt` para retiradas `SOLD` con pedido identificado de una migración auditable, tras fijar la semántica de las ventas alternativas.
