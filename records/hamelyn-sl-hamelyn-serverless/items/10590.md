## Summary

Gracias por el contexto: el panel de scrapers ya existe en la VM, pero `data-dashboards` aún no lo muestra ni ofrece el proxy autenticado y los permisos de escritura solicitados. La issue relacionada con versionar la plataforma se cerró tras incorporar ese servicio; no cubre esta integración.

## What This Changes

Añadir `/scrapers` a «Equipo técnico» para consultar el panel en directo y canalizar las acciones mediante un proxy con acceso de lectura y permisos `developers` para escritura.

## Best Possible Solution

Integrar la interfaz existente mediante una ruta de servidor autenticada que proteja el stream y las operaciones; la VM debe exigir el secreto compartido y validar los permisos `developers` para cada mutación.
