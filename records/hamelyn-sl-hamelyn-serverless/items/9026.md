## Summary

La incidencia sigue vigente en `dev`: el fallback fusionado hace visible el copy español en mercados regionales. Una PR abierta contiene una corrección pequeña, pero conviene confirmar que reutilizar el copy SEO regional es la política editorial deseada antes de integrarla.

## What This Changes

Corregir el hero de las minihomes para que los storefronts no españoles usen su descripción localizada en lugar del `heroDescription` español heredado.

## Best Possible Solution

Confirmar el uso de `config.tags.description` como copy regional del hero y, si se acepta, revisar e integrar la PR vinculada con una comprobación por mercado.
