## Summary

El enfoque corrige una incoherencia real de ventanas, pero el recibo puede caducar al cruzar el minuto reservado antes de que la API inicie la sesión. Conviene reparar esa carrera antes de fusionar.

## What This Changes

El PR añade una precondición de fuentes BigQuery para los watchers de marketplace, ajusta doce triggers de report y reprograma cuatro heartbeats y sus documentos operativos.

## Best Possible Solution

Vincular el recibo al slot que acreditó la espera y admitirlo durante su ventana de frescura, conservando la comprobación de fuentes y añadiendo una prueba del cruce de minuto.
