## Summary

El PR aborda una incidencia real de HTTP 429 en Casa del Libro, pero el límite fijo de 240 imports/h modifica el throughput de producción a partir de un umbral empírico y requiere validación operativa antes de integrarlo.

## What This Changes

El PR reserva un cupo compartido de 240 POST OF24 por hora para Casa del Libro y convierte las denegaciones locales en `MIRAKL_RATE_LIMITED`.

## Best Possible Solution

Mantener un único presupuesto CDL para OF24, tras confirmar con operación que 240/h preserva capacidad suficiente y añadiendo cobertura versionada de la reserva y de su normalización.
