## Label Justifications

- `P1`: La ruta de publicación de CLI falla para releases reales y bloquea la distribución de nuevas versiones hasta corregirse.

## Summary

El ajuste es coherente con el fallo descrito: el job de publicación configura Node antes de disponer de `pnpm`, pese a que el repositorio declara `pnpm@10.29.3`. No encontré defectos concretos en el diff; este PR sigue siendo necesario para recuperar las publicaciones de CLI.

## What This Changes

El PR añade `pnpm/action-setup@v6` con pnpm 10.29.3 antes de `actions/setup-node@v5` en el job `publish` de la release de CLI.

## Best Possible Solution

Mantener el paso explícito de pnpm antes de Node en `publish`, conservando la publicación con `npm` y validándolo en la siguiente ejecución real de `[Deploy] CLI`.

## Solution Assessment
