## What This Changes

El issue pide seleccionar variantes Mandrill disponibles para cambios de dirección y correlacionar los eventos ecommerce con el usuario asociado, sin asignar identidad a compras invitadas ni alterar contratos existentes.

## Best Possible Solution

Conservar destinatarios y plantillas actuales, validar las variantes contra el inventario publicado y propagar solo el identificador inequívoco de `checkout.user` o `notify.user` por el flujo completo, con pruebas para compras invitadas y deduplicación.
