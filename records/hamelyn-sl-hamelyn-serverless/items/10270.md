## Summary

Gracias por el reporte y el contexto: el código de `dev` confirma que Turbo no registra «Volver» en `hub`/`check`, y hay una PR abierta que propone cubrir esos casos. La issue debe seguir abierta hasta que esa PR se resuelva.

## What This Changes

Añadir «Volver» a Turbo para cancelar una re-decisión abierta y regresar desde `check` con un producto, manteniéndolo oculto en el hub vacío.

## Best Possible Solution

Incorporar el retorno de Turbo con acciones distintas para la re-decisión y la pantalla `check`, y conservar el botón oculto cuando no hay una acción de retorno.
