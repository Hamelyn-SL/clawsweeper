## Label Justifications

- `P1`: El fallo afecta una ruta de escritura ya implementada, aunque exige además un PAT con el scope correspondiente.
- `impact:security`: La combinación de scopes de token y rango de rol puede elevar autorización sobre una operación de escritura.

## Summary

La issue sigue siendo necesaria: `dev` mantiene un rango 7 para dashboards y una ruta de escritura con PAT combina ese rol con scopes persistidos, por lo que el doble gate puede quedar debilitado.

## What This Changes

Ajustar los rangos de `AuthRoles` para que `data-dashboards-user` no satisfaga mínimos operativos y `cli`/`developers` tengan rango explícito.

## Best Possible Solution

Mantener scopes y roles como dos barreras independientes: situar dashboards, CLI y developers en rango no operativo, añadir regresión de PAT/rango y comprobar los accesos del panel por nombre.

## Maintainer Decision

Required: false

## Reproduction Assessment

Sí, a nivel de código: un principal PAT con `write:warehouse` y solo `data-dashboards-user` supera numéricamente `ADMIN_LOGISTIC`. No se ejecutó una petición contra un entorno por tratarse de una revisión de solo lectura.

## Solution Assessment

Sí. Corregir la escala y añadir una regresión del gate es el camino más acotado; no cambia los scopes ni requiere una migración de roles más amplia.
