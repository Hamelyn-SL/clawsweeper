## Summary

La mejora de retirada de lotes ya está en `dev`, pero no elimina el problema central: precios y retiradas siguen reservando el mismo cupo de cinco feeds por vendedor y pueden competir por él. Mantendría este issue abierto para decidir cómo proteger las retiradas sin degradar la actualización de precios.

## What This Changes

El issue solicita evitar que los feeds de precio consuman el cupo compartido de Amazon y provoquen retrasos en las retiradas de lotes B2B.

## Best Possible Solution

Definir y documentar una política de cuota por vendedor que proteja las retiradas urgentes —por prioridad o capacidad reservada— y mantenga controlado el impacto sobre los feeds de precio, con pruebas de concurrencia entre regiones.

Required: true

Kind: product_direction

Question: ¿Debe el cupo de feeds de Amazon reservar capacidad o prioridad para retiradas frente a precios, o mantenerse compartido con otra estrategia de planificación?

Rationale: Separar cuotas, priorizar retiradas o combinar operaciones cambia qué trabajo puede consumir la capacidad limitada del vendedor y puede retrasar precios; el código por sí solo no determina la prioridad de negocio deseada.

Likely owner: JavierHamelyn

Owner reason: Ha trabajado recientemente en la reserva y los plazos de cuota de feeds de Amazon, por lo que es la referencia de código más cercana para concretar el impacto operativo.

Owner confidence: medium

Options:

- **Priorizar retiradas (recommended):** Mantener un cupo compartido, pero dar prioridad explícita a retiradas pendientes al asignar nuevos huecos.
- **Reservar capacidad:** Separar una parte del cupo por vendedor para retiradas, reduciendo capacidad disponible para precios.
- **Mantener cuota compartida:** Conservar la reserva actual y abordar los picos mediante planificación o tamaño de lote sin prioridad garantizada.

## Reproduction Assessment

Sí: el código actual reserva el mismo cupo de `JSON_LISTINGS_FEED` para ambos flujos; la telemetría y el resumen del PR enlazado aportan un caso concreto de denegación y reintento posterior.

## Solution Assessment

No hay una única solución técnica evidente: priorizar retiradas, reservarles capacidad o mantener el cupo compartido implican compromisos distintos para la cadencia de precios.
