## Summary

La incidencia sigue siendo necesaria: las tres consultas del dashboard aún clasifican con campos V1, mientras el mirror actual ya expone los campos V2 requeridos.

## What This Changes

Actualizar las métricas de sincronización y el desglose de no subidos para interpretar conjuntamente el histórico V1 y el estado V2 de marketplaces.

## Best Possible Solution

Centralizar la clasificación híbrida V1/V2 en `stock.ts`, aplicarla a snapshot, evolución y desglose, y retirar la etiqueta `BATCH` sin crear nuevas tablas o scheduled queries.
