## Summary

Se mantiene abierta: la corrección cubre dos huecos reales, pero aún registra como aparcado un huérfano cuya persistencia falló, dejando una telemetría contradictoria.

## What This Changes

La rama añade el contador `batched` tras persistir la marca de operación y devuelve `PERSISTENCE_FAILED` cuando falla el aparcado de un huérfano.

## Best Possible Solution

Separar el contador de huérfanos realmente persistidos, incrementarlo solo tras `landed`, y cubrir el resumen con el escenario de fallo de `RECORD_ERROR`.
