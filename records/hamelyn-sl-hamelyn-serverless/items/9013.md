## Summary

La incidencia sigue siendo necesaria: `dev` conserva un gate que bloquea cualquier acción preparada hasta que existan las 34 canónicas importadas en el estado de producción.

## What This Changes

Recuperar las escrituras de `issue-watchers` después de que la baseline legada no se importara en el namespace productivo.

## Best Possible Solution

Ejecutar una recuperación controlada que restituya las 28+6 firmas con su estado GitHub actual, pruebe un tick con acciones hasta `modelDispatched: true` y preserve la deduplicación histórica.
