## Summary

Gracias por el contexto: la revisión de Asamblea señala dos fallos concretos en la detección de imports runtime; ambos pueden dejar alertas descartadas sin revalidar o reabrir alertas por imports solo de tipos.

## What This Changes

El PR amplía el triage de Dependabot y añade auditoría periódica de descartes, revalidación de imports runtime, pruebas y documentación asociada.

## Best Possible Solution

Mantener la auditoría y revalidación propuestas, pero distinguir imports de tipos multilinea y limitar la comparación histórica a código runtime de producción antes de reabrir alertas.

## Maintainer Decision

Required: false

## Reproduction Assessment

Sí, por inspección del código: una importación de tipo multilinea puede activar una falsa revalidación, y un import existente en scripts de CI puede ocultar una nueva importación runtime.

## Solution Assessment

No todavía: el enfoque es adecuado para la necesidad descrita, pero debe separar referencias de tipos y scripts de herramientas del uso runtime de producción.
