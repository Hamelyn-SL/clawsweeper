- `P2`: La mejora corrige una base de escritura antes de que el piloto de mutaciones active la idempotencia en rutas de negocio.

## Summary

La migración sigue siendo necesaria: `dev` conserva MongoDB e índices TTL en ambos helpers, y la idempotencia aún no reserva la clave antes de ejecutar el handler.

## What This Changes

La issue propone mover la idempotencia y el rate limit de la API v6 desde colecciones MongoDB a Redis, con un KV dedicado y reserva atómica.

## Best Possible Solution

Implementar un store Redis dedicado que reserve atómicamente antes del handler, persista el resultado final y conserve límites, cabeceras y fail-open; retirar las colecciones MongoDB solo tras autorización expresa.
