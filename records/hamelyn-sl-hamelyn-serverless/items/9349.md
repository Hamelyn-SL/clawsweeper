## What This Changes

El PR migra PR Proof y los adjuntos multimedia de la wishlist del admin a la API privada de `user-attachments` de GitHub, manteniendo Vercel Blob para documentos y actualizando las skills de `gh`.

## Best Possible Solution

Integrar la migración tras verificar en staging los permisos de ambos tokens, una subida y resolución autenticada desde el admin, y la retirada efectiva de `GH_SESSION_TOKEN` solo cuando la vía nativa esté operativa.
