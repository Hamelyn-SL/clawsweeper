## Summary

La incidencia sigue siendo necesaria: `dev` aún dispara watchers de reportes sin una barrera verificable para raw y tipado, y existe un PR abierto que declara resolverla.

## What This Changes

Definir ventanas de fuentes completas y una precondición común para que los watchers de marketplaces no comparen datos de cortes temporales distintos.

## Best Possible Solution

Acordar el alcance de la barrera común y aterrizarlo mediante el PR vinculado, validando en despliegue las ventanas reales, alertas y recuperación de cada marketplace.
