## Summary

La issue sigue siendo necesaria: el modelo actual mezcla jerarquía, superficies y scopes, y no hay una PR vinculada ni una implementación equivalente en `dev`. El cambio necesita una decisión explícita sobre delegación de tokens y una migración de accesos por fases.

## What This Changes

La issue propone sustituir doce roles heredados por seis puestos jerárquicos y flags de superficie, con compatibilidad temporal y migración de asignaciones de Auth0.

## Best Possible Solution

Aprobar primero una matriz puesto→scopes→superficies y un modelo de tokens delegado; después migrar con doble lectura, pruebas de autorización y retirada explícita de los roles heredados.
