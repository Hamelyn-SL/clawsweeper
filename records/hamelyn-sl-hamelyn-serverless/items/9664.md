## Summary

La entrega sigue siendo necesaria: `dev` conserva los roles antiguos y la migración depende de una matriz de autorización y de compatibilidad aún no cerrada.

## What This Changes

Sustituye los doce roles acumulables por seis puestos jerárquicos y flags de superficie, con migración temporal de Auth0, admin, API v6 y CLI.

## Best Possible Solution

Aprobar una matriz única de puesto, flag, scope, operación y tipo de credencial; después migrar con doble lectura, pruebas de denegación y retirada controlada de roles heredados.
