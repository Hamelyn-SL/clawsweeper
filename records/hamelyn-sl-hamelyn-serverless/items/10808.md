## Summary

Gracias por el contexto. El código de alta/actualización no incluye `merchant_shipping_group`, pero eso no demuestra qué valor conservan los listings antiguos en Amazon ni cómo retirar uno ya guardado; conviene mantener abierto el tema para confirmar el comportamiento y decidir el tratamiento de esos SKU.

## What This Changes

Se pregunta si Hamelyn envía una plantilla de envío por SKU a Amazon y si los listings existentes pueden pasar a usar la plantilla predeterminada de Seller Central.

## Best Possible Solution

Confirmar con la API o Seller Central si los SKU antiguos tienen asignado un grupo de envío y qué operación permite retirarlo; después, decidir si se mantiene la configuración actual o se actualizan de forma controlada los listings afectados.
