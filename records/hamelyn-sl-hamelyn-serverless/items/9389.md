## Summary

Gracias por el contexto: el fallo sigue abierto; el admin exige el token y el snapshot deja dos Actions sin él, pero conservar o retirar el alta sin login requiere una decisión explícita.

## What This Changes

La incidencia solicita decidir y corregir las Actions de Auth0 que escriben usuarios sin enviar el token requerido por el endpoint del admin.

## Best Possible Solution

Conservar el aprovisionamiento tras el registro, añadir el secret y la cabecera a las dos Actions, y gestionar un export saneado y un despliegue reproducible antes de tocar el tenant.
