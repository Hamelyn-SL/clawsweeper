## Summary

Gracias por el contexto: el código confirma que POST y PUT requieren el token, pero sigue sin resolverse si las altas deben aprovisionar usuarios antes del primer login ni se ha contrastado el tenant activo. La issue sigue siendo necesaria.

La issue solicita resolver el 401 de las Actions de Auth0 y decidir si se conserva el aprovisionamiento al registrarse o se aplaza al primer login.

## Best Possible Solution

Confirmar el contrato de alta y contrastar las Actions activas; después, versionar y desplegar la opción acordada con una comprobación de alta sin login y del primer login.
