## Summary

La incidencia sigue siendo necesaria: el código actual exige token para los dos métodos y el snapshot histórico deja las dos Actions sin él; además, nadie ha resuelto la decisión sobre altas que nunca inician sesión.

## What This Changes

Corregir o retirar las Actions de Auth0 que escriben usuarios en el admin sin enviar `x-hamelyn-auth0-action-token`, y hacer reproducible su despliegue.

## Best Possible Solution

Mantener el aprovisionamiento al registrarse, recuperar primero un export saneado del tenant y versionar Actions, bindings y aplicación reproducible sin secretos.
