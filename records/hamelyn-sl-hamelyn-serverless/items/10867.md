## Summary

Gracias por el contexto: la API y el comando CLI ya están en `dev`, pero el cambio del workflow sigue en un PR abierto que referencia esta issue; conviene mantenerla abierta hasta que ese trabajo se resuelva.

## What This Changes

La petición es que el reporte diario use el CLI tanto para consultar los datos como para enviarlos desde el workflow, compartiendo cifras y texto con el admin.

## Best Possible Solution

Completar el cambio del workflow tras verificar sus prerrequisitos operativos y mantener la lectura del reporte sin efectos secundarios, reservando el envío y su protección contra duplicados para la ruta de envío.
