## Summary

El PR contiene una migración V2 útil, pero el switchover deja sin ejecución automática la actualización de datos y la recuperación legacy de AbeBooks. Además, aún falta una prueba operativa completa del cron V2 en el head actual.

## Best Possible Solution

Mantener programadas las funciones legacy sin equivalente V2 mediante una ruta de mantenimiento aislada, o ampliar el runner V2 hasta cubrirlas antes del switchover definitivo.
