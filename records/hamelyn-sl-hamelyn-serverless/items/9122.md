Mantengo este PR abierto: el gate evita un falso positivo útilmente, pero la detección inversa de backoffs usa una fecha futura y puede ocultar sets CDC perdidos persistentes.

## What This Changes

El PR amplía las instrucciones y el prompt de watchers para evaluar cohortes transitorias por IDs congelados en lugar de por diferencias de conteo.

## Best Possible Solution

Usar `lastUpdatedTimestamp` como tiempo causal de los backoffs, reflejarlo en ambas guías y conservar el gate por IDs para resolver https://github.com/Hamelyn-SL/hamelyn-serverless/issues/9073.
