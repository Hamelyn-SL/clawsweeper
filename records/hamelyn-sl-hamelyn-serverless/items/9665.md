## Label Justifications

- `P2`: Es una mejora amplia de permisos internos sin evidencia de una caída inmediata del servicio.
- `impact:security`: La petición redefine fronteras de autorización por rol en navegación y APIs administrativas.

## Summary

La issue sigue siendo necesaria: la migración de puestos exige una matriz funcional aprobada y coordinación entre menú, rutas y CLI antes de modificar permisos.

## What This Changes

La issue propone definir qué pantallas y acciones administra cada puesto y concentrar el admin en la operativa de almacén.

## Best Possible Solution

Aprobar una matriz pantalla × acción × puesto, aplicar una política única a navegación y endpoints, y retirar superficies al CLI solo cuando su autorización y operación equivalente estén verificadas.
