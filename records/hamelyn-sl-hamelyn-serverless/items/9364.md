## Summary

Gracias por el contexto: la corrección fusionada evita tombstonear un HTTP 400 ambiguo, pero sigue faltando telemetría individual de error y una decisión segura para retirar de la cola los rechazos persistentes.

## What This Changes

La incidencia solicita evitar reintentos silenciosos e indefinidos de retiradas eBay fallidas, registrar el resultado por oferta y diagnosticar los HTTP 400 con contexto de eBay.

## Best Possible Solution

Mantener los HTTP 400 ambiguos como reintentables, emitir un resultado saneado por SKU/oferta en cada error y definir con el equipo un estado terminal observable para rechazos persistentes.
