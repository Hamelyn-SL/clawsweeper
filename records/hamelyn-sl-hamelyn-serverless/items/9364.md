## Label Justifications

- `P1`: Una retirada persistente de stock vendido puede mantener una oferta eBay comprable y provocar sobreventa real.
- `impact:other`: El impacto concreto es la retirada incompleta de listings de marketplace, fuera de las categorías específicas disponibles.

## Summary

La issue sigue siendo necesaria: `dev` conserva los fallos ambiguos de retirada como reintentables, pero no impone un umbral terminal ni registra un resultado fallido individual con SKU y diagnóstico eBay.

## What This Changes

Evitar el bucle de retiradas eBay con HTTP 400 y hacer observables por SKU los fallos persistentes de `withdraw`.

## Best Possible Solution

Conservar el retry para ausencias no confirmadas, emitir un resultado de error saneado por SKU y definir una transición visible a parked o alerta tras un umbral aprobado.
