## Summary

La incidencia sigue siendo necesaria: `dev` conserva los HTTP 400 ambiguos como reintentables y no define un estado terminal ni telemetría individual suficiente para los rechazos persistentes.

## What This Changes

Solicita impedir el bucle de retiradas eBay con HTTP 400, registrar errores por oferta y decidir cómo tratar ofertas cuyo retiro sigue siendo ambiguo.

## Best Possible Solution

Definir un umbral de retirada que conserve el mirror, aparque y alerte para revisión operativa, con resultado individual saneado por SKU/oferta y verificación remota antes de cualquier tombstone.
