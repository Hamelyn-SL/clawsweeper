## Summary

## What This Changes

La incidencia pide impedir que las issues del admin introduzcan assets privados de GitHub sin un ticket de subida válido y revisar el alcance del token usado para resolverlos.

## Best Possible Solution

Conservar la validación de procedencia de assets nuevos y decidir, con evidencia del comportamiento de GitHub, cómo limitar el token y revisar las referencias preexistentes antes de dar por resuelto el riesgo.
