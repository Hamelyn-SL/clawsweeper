## Label Justifications

- `P0`: La vía actual puede exponer adjuntos privados de repositorios a los que alcance el token del servidor.
- `impact:security`: El defecto afecta al límite de autorización entre URLs controladas por usuarios y un token con acceso a GitHub.

## Summary

La issue sigue siendo necesaria: `dev` permite guardar URLs nuevas de assets de GitHub sin acreditar su subida y el resolver las acepta después por aparecer en la issue. El ticket no elimina esa vía al persistir.

## What This Changes

La issue solicita exigir un ticket HMAC de subida para cualquier URL nueva de assets de GitHub introducida en una issue del admin.

## Best Possible Solution

Validar en creación y edición todos los assets de GitHub que vayan a persistirse, incluidos los extraídos del Markdown, aceptando solo tickets válidos o URLs ya presentes en la misma issue.

## Solution Assessment

Sí: verificar el conjunto final de adjuntos antes de guardar preserva los existentes y evita depender de la comprobación posterior del resolver.
