## Label Justifications

- `P2`: El fallo impide obtener o deja incompleta la factura en pedidos divididos, con impacto relevante pero acotado a esa situación.

## Summary

Gracias por el caso concreto: el código actual sigue validando y firmando una sola parte del pedido, y el endpoint genera el PDF solo desde esa parte. La discusión confirma el fallo en un pedido real; la decisión pendiente es si contabilidad quiere una factura conjunta o una por parte.

## What This Changes

La issue solicita que la descarga de factura contemple las partes no canceladas de pedidos ecommerce divididos en varios `orderSell`.

## Best Possible Solution

Generar documentos que cubran todas las partes no canceladas, mantener el 404 solo cuando ninguna sea facturable y conservar la comprobación de email; aplicar el formato de factura que valide contabilidad.

No se reprodujo la descarga autenticada. Sí hay una ruta reproducible desde el código: el lookup selecciona una parte y rechaza su estado aunque existan otras partes facturables; el triage aporta además un pedido real como evidencia.

## Solution Assessment

No puede fijarse aún el formato final: consultar todas las partes y excluir las canceladas resuelve el fallo descrito, pero contabilidad debe decidir entre un PDF agregado y documentos separados.
