## Summary

Gracias por el contexto y las pruebas: la propuesta implementa el flujo solicitado, pero sigue pendiente la decisión de exponer este panel en data-dashboards; además, el iframe ejecuta código servido desde la VM bajo el mismo origen que la aplicación.

## What This Changes

Añade `/scrapers` a data-dashboards con un iframe para el panel de la VM, un proxy autenticado para datos y streaming, y acciones POST restringidas al rol `developers`.

## Best Possible Solution

Mantener la autorización y el control de acciones en el servidor, y aprobar la integración solo con un modelo de confianza explícito para el código del iframe; si no se confía en la VM para ejecutar código del mismo origen, servir el panel desde un origen aislado.
