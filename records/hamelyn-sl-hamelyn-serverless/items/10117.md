## Summary

Gracias por el contexto. El cambio parece coherente con los incidentes enlazados, pero dejaría el PR abierto: suprimir todas las alertas de snapshot por 5xx de Fnac es una decisión operativa explícita que aún necesita confirmación humana.

## What This Changes

El PR clasifica respuestas HTTP 5xx de Fnac ES/FR y evita publicar alertas de snapshot duplicadas desde la acción y el watcher, conservando la evidencia del fallo.

## Best Possible Solution

Mantener la clasificación estrecha y la evidencia FAILED, con una política de alertas para 5xx persistentes confirmada por el equipo antes de integrar el cambio.
