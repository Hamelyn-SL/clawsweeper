## Summary

La incidencia sigue siendo necesaria: `dev` no selecciona Mongo ni inyecta una URL elegida, y la PR que lo intentaba se cerró sin fusionarse tras detectar riesgos de migración y seguridad operativa.

## What This Changes

La incidencia propone seleccionar la base Mongo local con `dev:run --db=dev` y evitar que los `.env` por aplicación decidan el entorno silenciosamente.

## Best Possible Solution

Definir una migración compatible para `dev:run`, exigir una selección consciente para scripts locales con capacidad de escritura y validar ambos recorridos antes de reabrir una PR acotada.
