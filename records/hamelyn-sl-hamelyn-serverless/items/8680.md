## Summary

La migración sigue siendo necesaria: la dependencia V2 ya se integró, pero el contrato actual no permite un manager solo de pedidos sin inventar operaciones de stock para Alibris.

## What This Changes

Migrar Alibris a MarketplaceManager V2 para `process` y `ship`, manteniendo el exportador FTPS de inventario fuera del manager.

## Best Possible Solution

Permitir explícitamente managers solo de pedidos con pruebas de invariantes; cablear Alibris V2 para `process` y `ship` y conservar el exportador FTPS como hueco F3 documentado.
