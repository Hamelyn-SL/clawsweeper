## Summary

La migración sigue siendo necesaria, pero Alibris usa una exportación masiva FTPS con garantías propias que el contrato V2 actual no representa; necesita una decisión de diseño antes de implementarse.

## What This Changes

La incidencia solicita migrar la sincronización de Alibris a MarketplaceManager V2 reutilizando el código existente de pedidos y formateo.

## Best Possible Solution

Diseñar una capacidad V2 explícita para exportaciones declarativas por fichero, o conservar el exportador de inventario y migrar únicamente el wiring de pedidos cuando aporte valor verificable.
