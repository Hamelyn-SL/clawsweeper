## Summary

Gracias por el contexto: la migración sigue siendo necesaria, pero el contrato V2 vigente impide construir Alibris sin fingir operaciones de inventario; requiere una decisión de diseño antes del switchover.

## What This Changes

Migrar Alibris a `MarketplaceManager` V2, manteniendo el inventario FTPS externo y trasladando el cron principal tras las verificaciones operativas.

## Best Possible Solution

Definir y cubrir con tests un perfil V2 explícito solo-pedidos, conservar FTPS para purge y bajas, y solo después cablear `alibrisV2` con pruebas reales y switchover controlado.
