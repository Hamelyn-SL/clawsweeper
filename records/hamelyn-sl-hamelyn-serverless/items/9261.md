La incidencia sigue vigente en `dev`: Suecia selecciona `FEDEX_REGIONAL_ECONOMY`, pero el envío unitario intra-UE no incluye `customsClearanceDetail`. El reporte aporta además una validación real de FedEx tras forzar ese bloque.

## What This Changes

Añadir aduana para envíos intra-UE `FEDEX_REGIONAL_ECONOMY`, separar ETD de la aduana y cubrir el caso con pruebas de envío unitario y multibulto.

## Best Possible Solution

Separar `needsCustomsClearance` de `needsElectronicTradeDocuments`: exigir aduana para Regional Economy y multibulto, pero mantener ETD y la factura comercial solo para destinos no UE.
