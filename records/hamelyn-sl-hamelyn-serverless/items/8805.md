## Label Justifications

- `P1`: Un SKU maestro retirado puede seguir comprable mediante un listing histórico confirmado en Discogs.
- `impact:other`: El fallo afecta a la coherencia del catálogo y retirada en un marketplace externo.

## Summary

La incidencia sigue siendo necesaria: el recovery de Discogs detecta el listing histórico, pero no crea una retirada ejecutable cuando ya existe el documento `mk_discogs` del SKU.

## What This Changes

Corregir la retirada de listings históricos de Discogs que sobreviven tras sustituir `marketplaceId` y retirar el SKU.

## Best Possible Solution

Modelar una cola durable de IDs históricos de Discogs por SKU y drenarla con retiradas idempotentes, dejando intacto el `marketplaceId` activo o tombstoned.

## Maintainer Decision

Required: true

Kind: product_direction

Question: ¿Qué contrato permanente debe usar Discogs para conservar y retirar varios `listing_id` históricos asociados al mismo SKU?

Rationale: El modelo actual guarda una sola identidad por SKU; elegir entre una cola durable, un historial embebido u otra reconciliación condiciona compatibilidad, recuperación y migración de datos existentes.

Likely owner: MarcosTerroso

Owner reason: Su migración F2 introdujo el manager de Discogs que deberá respetar el contrato elegido.

Owner confidence: medium

Options:

- **Cola durable de retiradas (recommended):** Persistir IDs históricos pendientes y drenarlos con CAS e idempotencia, sin sobrescribir el mirror principal.
- **Historial embebido en el mirror:** Guardar una lista de IDs pendientes dentro del documento `mk_discogs` y adaptar el runner de retirada.

## Reproduction Assessment

Sí, a nivel de código: un `mk_discogs` existente impide que `SEED_WITHDRAWAL_SIGNAL` materialice el ID histórico detectado. La evidencia de API viva del informe completa el caso operativo.

## Solution Assessment

No con el mecanismo actual: volver a sembrar un mirror por SKU no funciona cuando ya existe el tombstone. Hace falta una representación explícita de IDs históricos pendientes.
