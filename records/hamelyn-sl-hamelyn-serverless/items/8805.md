## Summary

La incidencia sigue siendo necesaria: el flujo actual de Discogs sólo retira el `marketplaceId` vigente y no ofrece una ruta para retirar un listing histórico que ya no está referenciado.

## What This Changes

Corregir la retirada de listings históricos duplicados de Discogs cuando un SKU retirado ha reemplazado previamente su `marketplaceId`.

## Best Possible Solution

Añadir una reconciliación específica de Discogs que preserve o descubra IDs históricos y los retire de forma idempotente, con una limpieza controlada de los duplicados ya existentes.

## Maintainer Decision

Required: false

## Reproduction Assessment

Sí, por fuente: un fixture con dos IDs para el mismo SKU, seguido de retirada, demuestra que sólo se envía el `marketplaceId` vigente al adaptador. La comprobación API viva descrita en el reporte completa la reproducción operativa.

## Solution Assessment

No; retirar únicamente el ID actual no resuelve el duplicado histórico. La solución debe mantener una cola o señal de reconciliación de IDs sustituidos y probar ambos borrados.
