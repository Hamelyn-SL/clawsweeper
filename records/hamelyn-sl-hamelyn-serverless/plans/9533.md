# Coding Plan for hamelyn-sl/hamelyn-serverless#9533: MercadoLibre MX listings ignore product weight and dimensions and always use default package size

Source report: [records/hamelyn-sl-hamelyn-serverless/items/9533.md](records/hamelyn-sl-hamelyn-serverless/items/9533.md)

## Summary

La incidencia sigue vigente en `dev`: el alta de anuncios carga el `Product`, pero el formateador de paquetes solo consulta `stock.attributes.weight` y aplica el paquete predeterminado cuando falta ese campo.

## Plan

Corrige la creación de anuncios MercadoLibre MX para que `formatProductDimensions` reciba el `Product` y priorice `product.weight` junto con `product.dimensions.{depth,width,height}` cuando sean valores finitos y positivos. Conserva los tramos por peso para productos sin medidas y el paquete predeterminado como último recurso. Añade regresiones para medidas reales, solo peso válido y fallback. No cambies contratos externos, colecciones, datos persistidos ni `CHANGELOG.md`.
