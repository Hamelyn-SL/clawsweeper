## Label Justifications

- `P2`: La carencia afecta al flujo operativo de cancelación de un marketplace, sin evidencia de una interrupción general del runtime.
- `impact:message-loss`: El pipeline no comunica al marketplace las cancelaciones mediante el estado EDI `CN` esperado.

## Summary

Gracias por el contexto: el contrato documentado contempla enviar `CN` al cancelar, pero el manager actual de Alibris no habilita la fase de cancelación. La evidencia operativa aportada justifica mantener abierta la carencia; el conteo interno no acredita por sí solo el estado remoto.

## What This Changes

Añadir al flujo de pedidos de Alibris el envío EDI `.STA` con estado `CN` para las cancelaciones elegibles.

## Best Possible Solution

Completar el pipeline con selección de cancelaciones elegibles, envío idempotente de `CN` y trazabilidad por pedido, sin marcar la cancelación como confirmada por una mera subida FTP.
