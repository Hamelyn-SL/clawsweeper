## Summary

Mantener abierta: en `dev` el fallback de newsletter para las locales afectadas sigue renderizando una card centrada de `max-w-[560px]`, no el CTA desktop a ancho completo y dos columnas solicitado; además no hay PR abierto que cierre esta issue.

## What This Changes

La issue pide rediseñar en desktop el CTA de newsletter del footer para MX, AR, CO, UK, DE, NL, BR y US como bloque a ancho completo en dos columnas, manteniendo móvil igual.

## Best Possible Solution

Añadir una variante desktop del footer sin sell CTA que use el ancho `max-w-[1300px]` y dos columnas, reutilizando `FooterNewsletter` y `subscribeToNewsletter`, sin tocar el comportamiento móvil ni ampliar las locales del botón de venta.
