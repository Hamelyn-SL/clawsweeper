## Summary

La incidencia sigue siendo necesaria: `dev` recupera parcialmente algunos errores Cainiao, pero no resuelve de forma segura provincia/ciudad, PUDO ni la clasificación operativa que separa trabajo manual de fallos transitorios.

## What This Changes

La incidencia propone reducir los `LABEL_ISSUE` manuales mediante mejor clasificación de errores y recuperación segura de dirección, PUDO y carrier.

## Best Possible Solution

Separar primero la telemetría y el error estructurado; después aplicar normalizadores deterministas por país con pruebas y definir una política explícita de refresco o fallback para PUDO, sin cambiar carrier automáticamente.
