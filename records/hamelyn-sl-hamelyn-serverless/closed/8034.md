## Summary

La PR cubre un hueco real de observabilidad, pero la rúbrica aún puede ocultar una caída futura tras una pausa temporal y confunde la falta de frescura del materializado con un fallo de FTPS. También falta demostrar una emisión real del watcher antes de mergear.

## What This Changes

La rama añade al watcher de Alibris una señal `sales.order_ingestion_silent`, con umbrales, remediación y documentación operativa para detectar pedidos no ingeridos.

## Best Possible Solution

Mantener la señal, pero separar la frescura de datos de la severidad FTPS, reservar el dismiss para cierres permanentes y exigir evidencia real del pipeline antes de resolverla.
