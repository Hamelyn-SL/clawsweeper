## Summary

La issue sigue siendo necesaria: `dev` aún devuelve 500 y el PR de cierre continúa abierto. Además, el cambio propuesto a 404 no representa la causa observada, porque la evidencia operativa muestra lecturas transitorias de Blob cuyos PDFs vuelven a estar disponibles.

## Best Possible Solution

Añadir retry acotado con backoff corto a la lectura de Blob y lanzar `503 LABEL_TEMPORARILY_UNAVAILABLE` con el `labelId` cuando se agote; cualquier auditoría o reparación de datos debe mantenerse como script local no versionado y ejecutarse solo si aparece evidencia de blobs realmente ausentes.
