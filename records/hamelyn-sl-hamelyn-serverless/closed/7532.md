## What This Changes

Añade un agente cloud en `apps/agents` y un workflow por push a `dev` para detectar, validar y resolver automáticamente conflictos mecánicos en ramas de pull requests.

## Best Possible Solution

Ejecutar la resolución y las validaciones sin credenciales mutables, limitar los candidatos a ramas del repositorio base, rechazar entradas Git no regulares y aplicar desde un controlador aislado únicamente un parche verificado y acotado a los conflictos; después, demostrar el flujo completo sobre una rama desechable antes de activarlo.
