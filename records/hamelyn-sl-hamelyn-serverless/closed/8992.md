## Summary

El diagnóstico propuesto encaja con el flujo V2 y conserva sólo datos saneados, pero este PR cerraría una incidencia que también exige decidir cuándo un 400 de eBay deja de reintentarse.

## What This Changes

El PR extrae `errorId` y `message` de rechazos de envío de eBay, los registra saneados y los propaga al motivo de sincronización.

## Best Possible Solution

Mantener el diagnóstico saneado como paso independiente y dejar abierta la decisión de recuperación hasta definir una firma terminal exacta para eBay en ambos recoveries.
