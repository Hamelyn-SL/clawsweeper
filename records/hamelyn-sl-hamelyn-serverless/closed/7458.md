## Summary

Debe seguir abierto: en `dev` la configuración de Dependabot aún concentra el workspace raíz, `.github/scripts` y `apps/data-platform/**/source` en un único job npm, y mantiene todos los minors/patches en un solo grupo `minor-and-patch`. El PR relacionado abierto solo agrupa majors, así que no resuelve este timeout de minors.

## What This Changes

El issue pide dividir la configuración npm de Dependabot y granular los grupos minor/patch para que los jobs no agoten el límite interno de tiempo.

## Best Possible Solution

Separar el job npm raíz de los manifests auxiliares y dividir minor/patch por familias coherentes con la taxonomía de majors, manteniendo `target-branch: dev`, los ignores actuales y una validación posterior con un run real de Dependabot.
