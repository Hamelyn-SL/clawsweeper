## Summary

Gracias por el contexto: `dev` genera y guarda etiquetas Meli, pero no automatiza el lote diario ni define selección, horario, idempotencia o trazabilidad; sigue siendo necesaria una decisión operativa.

## What This Changes

La solicitud propone enviar de lunes a viernes por correo las etiquetas diarias de pedidos de Mercado Libre, excluyendo las ventas canceladas.

## Best Possible Solution

Definir un lote interno de etiquetas Meli ya creadas y no canceladas, con zona horaria, registro de envío, reintentos y prevención de duplicados antes de añadir el cron.
