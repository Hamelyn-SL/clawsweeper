## Summary

El PR ataca una regresión real de prerender, pero la nueva caché puede conservar counts vacíos durante 15 minutos cuando falle una reconstrucción desde Mongo.

## What This Changes

El PR encapsula las lecturas de counts y tasas de moneda en cachés de prerender, añade una caché para la metadata de `/flash-offer` y actualiza contratos y documentación.

## Best Possible Solution

Propagar el fallo de reconstrucción fuera del fill cacheado, o distinguirlo de un vacío legítimo, sin volver a hacer depender una lectura KV sana de Mongo.
