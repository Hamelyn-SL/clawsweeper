## Summary

El bug sigue presente en `dev` y el parche lo corrige de forma acotada, respetando el gate de reviewer solicitado. Antes de integrar, falta confirmar que `business-logic` deja de ser una exclusión operativa y retirar las atribuciones de IA prohibidas por la política del repositorio.

## What This Changes

El PR elimina `SKIP_LABELS` y el gate de `business-logic` para permitir que el agente solicite reviewer cuando no hay una asignación manual.

## Best Possible Solution

Acordar que una PR BL sin reviewer debe entrar en la asignación automática, preservar el gate de reviewers solicitados y publicar una revisión del PR sin atribuciones de IA.
