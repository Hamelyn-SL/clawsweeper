- `impact:ux-friction`: Los consolidados pesados requieren hoy una etiqueta manual cuando el flujo automático no puede resolver el peso.

## Summary

Mantener abierta: `dev` ya ofrece cambio manual Spring→FEDEX multibulto y deduplicación de PDFs consolidados, pero no cubre el routing por destinatario ni evita el etiquetado automático antes de conocer las cajas.

## What This Changes

La solicitud pide enrutar consolidados pesados de prep-centers a FEDEX, aplazar su etiqueta hasta packing y generar etiquetas multibulto sin duplicados.

## Best Possible Solution

Añadir una regla de ShipMatrix por destinatario normalizado y un estado explícito de consolidado pendiente de cajas; desde packing, generar o regenerar un único envío FEDEX por grupo con confirmación previa.

## Solution Assessment

No del todo: la base manual es reutilizable, pero aplicar routing directo sin decidir el estado pendiente y la regeneración dejaría el ciclo de etiquetas incompleto.
