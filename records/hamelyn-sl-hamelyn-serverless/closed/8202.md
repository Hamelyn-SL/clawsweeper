## Summary

La PR no debe cerrarse: su intención es razonable, pero puede marcar como correcto un triaje cuando una denegación bloqueó el descarte de una alerta o la creación de su issue de seguimiento. Además, la prueba publicada no llegó a ejecutar el guard con `jq` disponible.

## What This Changes

La rama cambia el guard de `[Deps] Alert Triage` para convertir denegaciones de permisos en `::warning::` y mantener como fallo solo los outcomes estructurados inválidos.

## Best Possible Solution

Permitir avisos para denegaciones inocuas, pero exigir que cada outcome `dismissed` o `issue_created` tenga un efecto remoto verificable antes de aceptar el run.
