## Summary

Gracias por el contexto. La revisión confirma que el flujo actual no puede enviar a Mirakl una oferta cuyo precio haya quedado como `undefined`: resuelve el precio de CDL con fallback al maestro y, si faltaran ambos, aborta antes del `POST`. El diagnóstico con datos vivos también encontró cero ejecuciones recientes con esta firma; la señal de crecimiento procede de documentos históricos tocados, no de nuevos intentos de alta.

## What This Changes

La incidencia pide corregir una supuesta pérdida del precio válido al construir ofertas de Casa del Libro.

## Best Possible Solution

Mantener el builder y la política actual; ajustar en un trabajo separado el heartbeat para contar transiciones nuevas o logs de ejecución y separar los registros `ACTIVE` de `WITHDRAWN`.
