## Summary

La propuesta reduce trabajo repetido de Coliseo, pero el gate clasifica como triviales cambios que sí pueden alterar la revisión o la resolución de dependencias; además quedan dos descripciones operativas incompletas o incorrectas.

## What This Changes

El PR añade un delta gate para conservar la revisión de Coliseo tras pushes sin lógica, usando compare de GitHub, un juez barato y una nota persistente en el comentario.

## Best Possible Solution

Limitar la reutilización automática a contenido realmente no ejecutable y obligar a revisar deltas de guidance, skills y lockfiles; después, alinear la documentación con todos los fallbacks seguros.
