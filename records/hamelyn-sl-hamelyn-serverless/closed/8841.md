## Summary

## What This Changes

La incidencia solicita un servicio local de MongoDB MCP compartido por HTTP en macOS, con instalación idempotente, credenciales fuera de la lista de procesos y guía de migración para clientes de agentes.

## Best Possible Solution

Acordar un setup macOS soportado que fije la dependencia, limite la escucha a loopback, use `readOnly`, guarde el secreto con permisos estrictos y documente reinicio, rollback y migración de cada cliente.
