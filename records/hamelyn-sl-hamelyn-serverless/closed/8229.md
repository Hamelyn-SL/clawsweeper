## Summary

La corrección sigue siendo necesaria en `dev` y la revisión previa ya está resuelta; esta PR es la candidata concreta para cerrar el fallo de cupón en carritos anónimos.

## What This Changes

La rama alinea el `cartId` del carrito optimista con el identificador persistido y devuelto por la API, y añade `invalidCartError` en nueve diccionarios de checkout.

## Best Possible Solution

Integrar la reconciliación validada y conservar el fallback seguro para IDs legacy, de modo que estado, `localStorage` y backend compartan siempre el mismo carrito anónimo.

## Solution Assessment

Sí: reutilizar el ID persistido, validarlo antes de construir el `ObjectId` y aceptar el ID canónico del servidor ataca la divergencia sin introducir otra ruta de carrito.
