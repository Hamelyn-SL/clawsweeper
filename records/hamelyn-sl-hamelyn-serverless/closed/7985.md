- `merge-risk: 🚨 security-boundary`: La migración a `pull_request_target` usa secretos del repositorio y depende de una App dedicada para publicar checks.

## Summary

La propuesta resuelve un problema real de trazabilidad de Proof, pero introduce fallos concretos de recuperación, notificación y elegibilidad que impiden usarla como gate fiable todavía.

## What This Changes

La rama migra PR Proof a un controlador v2 autoritativo con `pull_request_target`, polling de estado firmado, reconciliación del body y reruns históricos ligados a SHA.

## Best Possible Solution

Corregir las rutas de recuperación, eventos auxiliares y documentación, y validar un canario completo desde GitHub Actions antes de exigir `proof-evidence` como check requerido.
