## Label Justifications

- `P2`: Es una corrección necesaria de infraestructura interna con alcance limitado a PR Proof, sin evidencia de una emergencia de producción.

- `merge-risk: 🚨 automation`: El formato estructurado se destina a reintentos automáticos y actualmente puede modificar los valores de las acciones al publicarlos.

## Summary

Debe seguir abierto: `dev` todavía conserva el checkout mediante credencial dentro de la microVM, por lo que la corrección sigue siendo necesaria, pero el head actual altera valores del plan JSON y no aporta prueba diagnóstica suficiente de la nueva frontera de credenciales.

## What This Changes

El PR sustituye el checkout con `GIT_ASKPASS` por credenciales inyectadas en egress, añade estados y bloqueos estructurados a PR Proof y actualiza el formato público y las pruebas asociadas.

## Best Possible Solution

Mantener el credential broker de egress, serializar el bloqueo con escapes JSON que conserven los valores originales, añadir una regresión con placeholders y aportar logs redacted de los caminos con snapshot y fallback que prueben el fetch, la restauración de red y la ausencia del token antes de ejecutar código del PR.
