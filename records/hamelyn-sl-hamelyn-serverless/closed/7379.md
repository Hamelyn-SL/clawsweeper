## What This Changes

La incidencia solicita retirar o recuperar listings activos de Amazon ES que carecen de documento `mk_amazonEs` y quedan fuera del pipeline canónico de retirada.

## Best Possible Solution

Revalidar la cohorte y rehidratar por lotes pequeños el documento mínimo de `mk_amazonEs` para que el pipeline canónico retire, clasifique errores y limpie cada listing, añadiendo después reconciliación inversa periódica si el patrón continúa apareciendo.
