## Label Justifications

- `merge-risk: 🚨 compatibility`: Los cambios pueden alterar estados y stock de pedidos existentes durante una actualización.

## Summary

Gracias por la contribución: el objetivo corrige un problema real, pero el parche puede cancelar un pack activo, sobrescribir estados concurrentes y bloquear el resto del sweep; necesita correcciones y prueba real antes de fusionar.

## What This Changes

El PR añade un sweep horario de cancelaciones y reclamos de MercadoLibre, desbloquea pedidos con etiquetas recuperadas y evita etiquetas mock para packs cancelados.

## Best Possible Solution

Conservar el sweep, pero verificar cada pack completo, aplicar transiciones compare-and-set desde estados preenvío y aislar errores por pedido antes de validar un dry-run real y trazable.
