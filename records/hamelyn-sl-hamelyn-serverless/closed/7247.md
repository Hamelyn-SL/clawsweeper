## Summary

Mantendría este PR abierto: el cambio es pequeño y coherente con el patrón ya aplicado en `ci.yml`, y `dev` aún no tiene el trigger `push` en `rust-ci.yml`. No veo un defecto de parche, pero falta prueba real del comportamiento de caché antes de mergear.

## What This Changes

El branch añade a `.github/workflows/rust-ci.yml` un trigger `push` en `dev` con los paths del CLI Rust para sembrar la caché de Cargo.

## Best Possible Solution

Mantener el cambio acotado al trigger de `rust-ci.yml` y verificar tras merge que un push a `dev` guarda caché de Cargo reutilizable por PRs nuevos.
