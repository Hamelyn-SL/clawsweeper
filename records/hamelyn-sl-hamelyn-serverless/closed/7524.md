## Summary

El fallo sigue presente en `dev`: varias rutas Admin aún convierten errores tipados en 500 y Exotec mantiene la clasificación genérica de `BIN_DEFINITION_ERROR`. El PR enlazado continúa abierto, por lo que esta issue debe permanecer abierta hasta que se integre o se descarte.

## What This Changes

La issue solicita preservar los estados HTTP de `BaseError` en rutas Admin y clasificar como 4xx los errores semánticos de entrada o conflicto devueltos por Skypod.

## Best Possible Solution

Centralizar el manejo de errores para preservar `BaseError.status` en Admin y normalizar la respuesta de Skypod por semántica: 409 para conflictos de estado, 422 para entradas inválidas y 502/500 para transporte o fallos del proveedor.

## Solution Assessment
