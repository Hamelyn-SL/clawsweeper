## Label Justifications

## Summary

La incidencia sigue siendo necesaria: `dev` aún devuelve el 404 para rutas con mayúsculas y un PR abierto ya contiene una corrección específica que debe integrarse antes de cerrar.

## What This Changes

Redirigir con 301 las rutas válidas de ecommerce con mayúsculas a su URL canónica en minúsculas, sin alterar las fichas de producto.

## Best Possible Solution

Revisar e integrar el PR enlazado tras confirmar en storefronts reales las redirecciones por locale, query string y exclusiones de fichas de producto.

## Solution Assessment
