## Summary

La incidencia sigue siendo necesaria: `dev` aún convierte un chunk de Catalog API agotado por 429 en `No ASIN found for this EAN`, mientras el PR abierto https://github.com/Hamelyn-SL/hamelyn-serverless/pull/7782 concentra la corrección pendiente.

## What This Changes

Evitar que los 429 agotados de Amazon Catalog API se registren como ASIN no encontrado y queden fuera de la recuperación transitoria.

## Best Possible Solution

Fusionar https://github.com/Hamelyn-SL/hamelyn-serverless/pull/7782 tras validar en un flujo real que un 429 agotado reintenta como `TRANSIENT` y que un EAN ausente real continúa como `STALE`; valorar cuota distribuida solo si persiste el throttling.
