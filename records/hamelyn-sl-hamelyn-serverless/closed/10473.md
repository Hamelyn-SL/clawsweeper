## Summary

El cambio aborda el problema concreto de reencolar retiradas completadas y tiene evidencia cuantitativa y pruebas específicas. Mantendría abierto este PR hasta que se confirme la ventana de hasta 24 horas si Amazon no aplica un DELETE aceptado; la issue asociada sigue abierta.

## What This Changes

El PR añade un corte temporal opcional a `forceSetStatusAsActive` y lo aplica al report de Amazon para diferir filas modificadas en los 90 minutos anteriores a la solicitud.

## Best Possible Solution

Conservar una guarda atómica basada en `requestedAt` para no reactivar retiradas recientes, y dejar explícito que el equipo acepta el retraso máximo hasta el siguiente report cuando la propagación remota falla.
