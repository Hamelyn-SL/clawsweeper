## What This Changes

El PR añade al knowledge de marketplaces una explicación del ciclo terminal de filas `mk_`, criterios para detectar huérfanos reales, falsos positivos de los watchers y una vía de recuperación para listings Amazon sin fila local.

## Best Possible Solution

Documentar una matriz breve por tipo de transición —venta en el canal, withdraw síncrono confirmado y withdraw batch— indicando en cada caso si la fila se borra o permanece, y mantener aparte el criterio específico de huérfanos Amazon.
