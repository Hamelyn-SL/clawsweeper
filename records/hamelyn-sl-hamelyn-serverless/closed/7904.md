## Label Justifications

- `P1`: La ausencia silenciosa de despliegue ya bloqueó el login del CLI para usuarios con rol `cli` y puede volver a afectar cambios de autenticación.
- `impact:auth-provider`: El incidente observado dejó una política antigua de scopes en producción y rechazó la creación de tokens del CLI.

## Summary

La incidencia sigue siendo necesaria: el pipeline actual no selecciona ni puede invocar `hamelyn-api`, mientras Vercel mantiene desactivado su despliegue Git directo. El comentario de triage aporta además una simulación local positiva para la reparación propuesta, pero faltan los hooks operativos.

## What This Changes

Añadir `hamelyn-api` al despliegue dirigido desde `dev` y `master`, incluyendo hooks, selección por cambios, cobertura del enrutado y documentación.

## Best Possible Solution

Provisionar los dos hooks con acceso de plataforma y ampliar el pipeline para seleccionar `api` por cambios propios, de runtime compartido y manualmente; después verificar un despliegue dirigido en ambas ramas.
