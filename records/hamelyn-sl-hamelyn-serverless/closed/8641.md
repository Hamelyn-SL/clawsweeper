## Summary

Mantener abierto: la caché CDN propuesta puede servir aciertos sin ejecutar el limitador de aplicación, anulando el tope de 60 por IP que el PR declara para evitar scraping masivo.

## What This Changes

El PR añade un límite específico de 60 solicitudes por minuto al catálogo público y cachea sus respuestas correctas en CDN.

## Best Possible Solution

Mantener el tope por IP antes de servir cualquier HIT de CDN mediante un control de borde compatible, o retirar la caché compartida si ese control no puede garantizarse; actualizar la documentación del esquema persistido.
