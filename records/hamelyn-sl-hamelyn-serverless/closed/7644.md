## Summary

Debe seguir abierta: `dev` todavía rechaza HTML tanto en el selector como en la allowlist del servidor, y el trabajo ya está correctamente emparejado con un PR abierto que declara resolverla. Ese PR aún necesita una decisión explícita sobre la entrega segura de contenido HTML activo y prueba real del flujo autenticado antes de poder cerrar la issue.

## What This Changes

Permitir adjuntar archivos `.html` y `.htm` a las wishlist creadas desde Admin.

## Best Possible Solution

Admitir `.html` y `.htm` únicamente como adjuntos descargables, validando el MIME y el límite de 10 MB en servidor, manteniendo el enlace no incrustado y verificando que el almacenamiento fuerza descarga o aísla totalmente la ejecución del origen de Admin.
