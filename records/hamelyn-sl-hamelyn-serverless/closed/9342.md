- `impact:other`: El impacto confirmado es agotamiento operativo de cuota y capacidad de creación, fuera de las clases específicas disponibles.

## Summary

La incidencia sigue siendo necesaria: el flujo actual reintenta todos los `DUPLICATE_ACTIVE_LISTING` y solo libera candidatos según el mirror local, sin distinguir anuncios propios remotos desconocidos de rechazos permanentes.

## What This Changes

Determinar el destino correcto de duplicados de MercadoLibre para que no consuman la cola de creación mientras se recuperan de forma segura los anuncios propios existentes.

## Best Possible Solution

Añadir una reconciliación remota acotada para duplicados desconocidos, promoviendo solo anuncios propios verificables y aparcando con causa estable los demás rechazos.

## Maintainer Decision

Required: true

Kind: product_direction

Question: ¿Debe MercadoLibre reconciliar y promover un anuncio remoto propio al recibir `DUPLICATE_ACTIVE_LISTING` cuando el mirror local no lo conoce?

Rationale: El código actual define deliberadamente el duplicado como reintentable, pero elegir entre recuperar anuncios propios y aparcar rechazos desconocidos cambia el contrato operativo y la seguridad del enlace remoto.

Likely owner: MarcosTerroso

Owner reason: El historial le vincula directamente con la migración y el diseño del reencolado de MercadoLibre.

Owner confidence: high

Options:

- **Reconciliar y promover anuncios propios (recommended):** Buscar el anuncio por una identidad remota fiable, enlazarlo solo tras validar propiedad y estado, y aparcar el resto de duplicados.
- **Aparcar duplicados desconocidos:** Evitar nuevos intentos ejecutables cuando el mirror no tenga el anuncio, priorizando cuota y estabilidad sobre recuperación automática.
- **Conservar el reintento actual:** Mantener el backoff y el reencolado local existentes, aceptando el consumo de cola hasta disponer de una solución posterior.

## Reproduction Assessment

Sí, a nivel de código: un error `DUPLICATE_ACTIVE_LISTING` entra como `transient` y el reencolado consulta únicamente el mirror local por EAN.

## Solution Assessment

No todavía: promover o aparcar requiere definir primero la política para duplicados remotos desconocidos y la identidad segura con la que se validarán.
