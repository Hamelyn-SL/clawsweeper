## Summary

El cambio de alertas de snapshot está acotado y cubierto por pruebas, pero el nuevo aviso de autofix puede quedar perdido: se añade `autofix-failed` antes de publicar el comentario y los siguientes intentos omiten el PR al ver esa etiqueta.

## What This Changes

El PR añade autocierre de alertas de snapshot tras ejecuciones correctas y sustituye las issues de fallos del autofix de dependencias por comentarios en el PR afectado.

## Best Possible Solution

Mantener el autocierre de snapshots y hacer que la deduplicación del autofix solo impida comentarios que ya se publicaron correctamente.

## Reproduction Assessment
