## Summary

Gracias por el contexto: el cambio aborda el falso aviso, pero la issue vinculada sigue abierta y asignada a JavierHamelyn. Además, desplegar el endpoint sin `SUPPLY_APP_VERSION` deja a las builds antiguas sin avisos de actualización; hace falta confirmar cómo se protegerá esa transición.

## What This Changes

Supply compara la versión anunciada con la nativa instalada y la API admite objetivos por tienda para builds que declaran la estrategia `native`.

## Best Possible Solution

Conservar el arreglo nativo y desplegarlo con una transición compatible: mantener el override global hasta que las builds con comparación nativa estén disponibles y configurar después los objetivos por tienda.
