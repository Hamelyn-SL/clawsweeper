## Summary

This should stay open: current code already records Mercado Pago payments in Stripe as off-Stripe Payment Records, but the requested refund-from-Stripe workflow is still missing and needs payment-operations direction.

## What This Changes

Request Mercado Pago ecommerce payments to appear in Stripe in a way that lets operators refund them from Stripe instead of logging into Mercado Pago or Mercado Libre.

## Best Possible Solution

Provide one supported refund workflow: either an internal action that refunds in Mercado Pago and reconciles the result in Stripe where possible, or a deliberate migration to a Stripe-native Mercado Pago processing path if Stripe can own those refunds end to end.
