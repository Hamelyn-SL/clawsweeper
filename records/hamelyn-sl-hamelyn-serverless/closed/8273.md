## Summary

La issue sigue siendo necesaria: `dev` aún omite el enlace de Stripe cuando el cobro externo de MercadoPago no tiene `paymentIntentId`, y existe una PR abierta que declara resolver exactamente ese caso.

## Best Possible Solution

Integrar una corrección que preserve el enlace directo de `PaymentIntent` y genere una búsqueda Stripe codificada para `PaymentRecord` de MercadoPago, incluidos los registros históricos.

## Solution Assessment
