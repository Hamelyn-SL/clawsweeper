## Summary

La mejora sigue siendo necesaria: `dev` aún ejecuta el gate completo para cualquier cambio y no hay un PR abierto que la implemente. Debe mantenerse abierta para revisión del equipo de plataforma, porque la arquitectura propuesta es válida pero la allowlist original incluye Markdown, skills y assets que también pueden actuar como entradas de runtime o automatización.

## What This Changes

La issue solicita mantener verde el check requerido `Lint and typecheck` mientras se omiten instalación, lint, typecheck y tests cuando todos los cambios sean exclusivamente no ejecutables.

## Best Possible Solution

Conservar siempre el job requerido y añadir un clasificador local y conservador que solo marque como seguros directorios documentales explícitos, falle hacia la ejecución completa ante cualquier path desconocido o mixto y evite incorporar una acción de terceros innecesaria.
