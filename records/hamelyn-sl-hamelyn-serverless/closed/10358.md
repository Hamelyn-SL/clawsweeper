## Summary

Gracias por aclarar el alcance: la documentación de `main` aún presenta el piloto como configurable para varios marketplaces, mientras que solo eBay ES tiene el job de cola. El cambio propuesto cubre esa discrepancia concreta, así que no hay base para cerrar este PR como ya resuelto.

## What This Changes

Aclara en dos páginas que el despacho por cola solo está habilitado para eBay ES y que las demás claves de `WATCHER_QUEUE_MARKETPLACES` no tienen efecto hasta adaptar sus workflows.

## Best Possible Solution

Mantener ambas páginas alineadas con los workflows reales: nombrar eBay ES como único marketplace del piloto, describir el fallback al trigger existente y aclarar que otras claves aún no activan el despacho por cola.
