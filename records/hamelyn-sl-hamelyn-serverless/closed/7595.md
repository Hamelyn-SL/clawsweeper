## What This Changes

Investigar y corregir que los productos marcados como `roto` durante el picking de Skypod no generen sustituto ni pasen a cancelación cuando no existe uno.

## Best Possible Solution

Mantener un único flujo estación → `PickingOp` → generación de packing y añadir cobertura de regresión para que un producto Skypod marcado `BROKEN` cree `S-EX` con alternativa o ejecute la cancelación parcial prevista cuando no haya stock.
