## Summary

Mantengo este PR abierto: el cambio cubre una necesidad real enlazada con https://github.com/Hamelyn-SL/hamelyn-serverless/issues/7258, pero todavía falta prueba de comportamiento real y hay riesgo operacional porque el export diario de Alibris empezaría a escribir audit en Mongo en cada ejecución y puede fallar con exit code 3 si esa persistencia falla.

## What This Changes

El PR modifica `apps/marketplace-crons/scripts/alibris-inventory-export.mjs` para upsertar un documento `config/alibrisInventoryExportAudit` con el estado del export/upload de Alibris, metadata de GitHub Actions y la última subida correcta.

## Best Possible Solution

Aterrizar una persistencia de audit con prueba redaccionada de una ejecución real o equivalente, dejando claro el contrato `data.lastRun`/`data.lastSuccessfulUpload` y el impacto operacional de los nuevos exit codes antes de merge.
