- `P2`: Es una mejora planificable de integridad de datos: el pipeline horario funciona, pero las colecciones nuevas todavía requieren un backfill manual para quedar completas.

## Summary

Debe seguir abierta: `dev` todavía no siembra el histórico de una colección nueva y https://github.com/Hamelyn-SL/hamelyn-serverless/pull/7631 es el PR abierto que declara resolver este trabajo; la issue debe permanecer como seguimiento canónico hasta que esa implementación se valide y se fusione.

## What This Changes

Automatizar el seed del baseline de BigQuery al registrar una colección nueva en `bq-merge`, compartiendo el registro de colecciones y ejecutando la reconciliación tras el despliegue.

## Best Possible Solution

Mantener un único registro versionado de colecciones y tipos de `source_data`, detectar de forma conservadora las tablas sin baseline y ejecutar una reconciliación idempotente tras el despliegue, con prueba controlada de Dataflow y verificación de conteos antes de habilitarlo en producción.
