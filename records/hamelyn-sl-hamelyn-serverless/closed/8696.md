## Summary

El PR sigue siendo necesario para el objetivo de OpenAPI, pero el mismo commit actual conserva varios fallos de contrato y elimina sin transición un campo público de discovery. Antes de mergearlo necesita una decisión sobre el contrato de retirada y una prueba real posterior a las correcciones.

## What This Changes

El PR registra `ApiError` como esquema reutilizable de OpenAPI, introduce `deprecated.sunset` para marcar operaciones y emitir cabeceras de retirada, y elimina el bloque `cli` del índice público de la API.

## Best Possible Solution

Definir un contrato público único con fecha de deprecación y retirada, preservar o deprecar explícitamente `data.cli`, y aplicar las cabeceras y validaciones a todas las rutas registradas antes de regenerar el spec.
