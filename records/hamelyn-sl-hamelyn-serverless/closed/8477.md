## Summary

La issue sigue siendo necesaria: el menú reserva Usuarios a `admin-user`, pero las APIs de usuarios permiten a `admin-logistic` leer, crear y modificar cuentas y roles; además, falta decidir el roster y la frontera autorizativa antes de reasignar permisos.

## What This Changes

La issue solicita auditar roles del Admin, retirar privilegios `admin-user` innecesarios y alinear los paneles y APIs visibles con las funciones reales de logística.

## Best Possible Solution

Definir una matriz explícita de lectura y escritura por rol, reservar la gestión de roles al rol aprobado y ejecutar una reconciliación controlada de Mongo y Auth0 con verificación por usuario.
