## Summary

El PR sigue siendo necesario para frenar las lecturas SSR al KV, pero no está listo para mergear: un fallo de invalidación deja el contenido de Admin obsoleto hasta 24 horas y falta prueba real posterior al cambio.

## What This Changes

Cachea por locale la lectura de Promo Strip en Vercel Data Cache, invalida cada storefront tras guardar desde Admin y muestra los fallos parciales de revalidación.

## Best Possible Solution

Mantener la caché por locale y la invalidación bajo demanda, pero fijar un respaldo de cinco minutos como máximo y demostrar el flujo completo contra un KV operativo antes del merge.
