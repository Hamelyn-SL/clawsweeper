Full review comments:

- **[P2] Espera el reporte antes de cerrar el stream:** `apps/agents/agent/lib/usage-middleware.ts:41-58`
  - body: Este `void reportUsageSafe` deja la escritura de telemetría en background justo cuando el stream termina. En Vercel/Next el runtime puede congelar la invocación al acabar la respuesta, así que los watchers pueden perder el evento que este PR quiere capturar; haz el `transform` async y espera el reporte seguro antes de `enqueue`.
  - confidence: 0.84
- **[P2] Cachea la promesa de conexión Mongo:** `apps/agents/lib/usage-store.ts:22-26`
  - body: Aquí `client` se asigna antes de que `connect()` termine; una llamada concurrente puede saltarse el `await` inicial y usar el cliente durante una conexión pendiente, y un fallo deja el cliente cacheado sin reset. Sigue el patrón local de `clientPromise` para que todos los callers esperen la misma conexión y se pueda reintentar tras error.
  - confidence: 0.76
