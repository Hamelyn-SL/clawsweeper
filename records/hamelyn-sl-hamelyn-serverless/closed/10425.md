## Label Justifications

## Summary

Gracias por el contexto: el cambio aborda el problema del carrito, pero el corte temporal se calcula al ejecutar la limpieza y puede borrar una línea añadida después de iniciar el checkout. Además, la ruta deja de aceptar clientes antiguos; hace falta resolver ese riesgo antes de cerrar la revisión.

## What This Changes

El PR sustituye el vaciado completo por una retirada de las líneas compradas, coordinada entre el webhook y la confirmación, y ajusta la sincronización del carrito y sus mensajes.

## Best Possible Solution

Capturar un corte temporal ligado al inicio del checkout y usarlo en la retirada; además, definir y validar una transición segura para clientes antiguos antes de exigir `checkoutId`.
