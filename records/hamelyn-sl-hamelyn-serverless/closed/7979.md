## Summary

La migración tiene una comparación real BigQuery/Mongo útil, pero no debe integrarse hasta evitar que un timeout de frescura publique un informe de Skypod con datos deliberadamente stale.

## What This Changes

Migra el inventario esperado del informe mensual de Skypod de MongoDB a BigQuery, añade un gate de frescura y conserva Mongo como fuente manual alternativa.

## Best Possible Solution

El cron debe publicar el resumen solo con BigQuery fresco; si no lo está, debe fallar y notificarlo, dejando `source=mongo` como recuperación manual explícita.
