## Label Justifications

- `P1`: La evidencia operativa relaciona retiradas falsas con compras posteriores que terminan canceladas al cliente.
- `impact:other`: El fallo deja inventario vendido disponible en un marketplace y genera cancelaciones operativas posteriores.

## Summary

Gracias por el reporte: el flujo actual todavía convierte un `404` de DELETE en `gone` y el runner lo consolida como retirada correcta, así que esta incidencia sigue siendo necesaria.

## What This Changes

Evitar que una retirada de TodoColección trate cualquier `404` del DELETE como `gone` sin confirmar la ausencia remota del anuncio.

## Best Possible Solution

Solo consolidar el tombstone tras confirmar que el anuncio ya no existe; si la consulta por SKU devuelve un id vivo, retirar contra él, y si queda indeterminado, registrar un error reintentable con estado y clave remotos.

## Maintainer Decision

Required: true

Kind: product_direction

Question: ¿Debe la corrección reintentar automáticamente el DELETE con el id resuelto por SKU o aparcar cualquier `404` ambiguo para reconciliación posterior?

Rationale: Las dos opciones eliminan el falso éxito, pero difieren en si el flujo puede ejecutar un segundo borrado remoto con efectos adicionales.

Likely owner: HamelynDev

Owner reason: La procedencia disponible lo conecta directamente con la capa V2 que define la reconciliación vigente.

Owner confidence: high

Options:

- **Reintento verificado (recommended):** Resolver por SKU y reintentar únicamente cuando la identidad del anuncio y la respuesta de borrado se puedan validar de forma acotada.
- **Aparcar ambiguos:** Convertir el `404` ambiguo en error reintentable y reservar la retirada para una reconciliación posterior.

## Reproduction Assessment

Sí, en código: un `404` de `deleteProduct` entra directamente en `gone` y el runner lo persiste como éxito; no se ejecutó una llamada real al proveedor.

## Solution Assessment

Incierto: verificar por SKU es la dirección adecuada, pero el equipo debe decidir si el reintento remoto es seguro frente a referencias ambiguas.
