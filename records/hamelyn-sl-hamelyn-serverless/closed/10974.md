## Summary

El cambio cubre una parte concreta del problema de autenticación y no encuentro un defecto funcional confirmado en el diff. Mantengo la PR abierta porque la eliminación de las exenciones de Exotec puede afectar a clientes sin sesión, y la discusión de seguridad aún pide decidir qué excepciones de integración deben conservarse.

## What This Changes

Añade autorización por roles a rutas administrativas, adapta llamadas del frontend para enviar el token y valida el token de subida antes de generar permisos de Vercel Blob.

## Best Possible Solution

Conservar la autorización de las rutas administrativas y definir explícitamente qué llamadas Exotec requieren una sesión Auth0 y cuáles necesitan un mecanismo verificable de autenticación de integración.
