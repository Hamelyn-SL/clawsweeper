## Summary

La issue sigue siendo necesaria: el vídeo muestra el flujo inmediatamente posterior a una venta y `dev` todavía puede presentar un fallo de consulta como si el usuario no tuviera ventas, sin error ni reintento.

## What This Changes

Se solicita corregir la carga intermitente del panel «Perfil > Ventas» de Supply, que puede mostrar «No hay ventas» después de completar una venta.

## Best Possible Solution

La vista debe distinguir carga, error y vacío confirmado, ofrecer un reintento o refresco al recuperar foco y conservar la lista previa; solo debe modificarse autenticación o backend si una captura de red demuestra que allí nace la carrera.

## Solution Assessment

Aún no del todo: el objetivo es correcto, pero la solución más segura debe empezar separando error y vacío y añadiendo refresco, sin recuperar automáticamente la sincronización de Auth0 descartada ni cambiar el backend sin evidencia.
