## Label Justifications

## Summary

La causa sigue presente en `dev`, pero esta PR no está lista para mergear: introduce un defecto bloqueante en el estado persistido de las etiquetas diferidas y carece de prueba runtime observable.

## What This Changes

La PR centraliza la propagación de datos de envíos consolidados en `runCarrierCreateShipment`, adjunta las etiquetas descargadas al resultado y añade recuperación de etiquetas y el estado `LABEL_NOT_READY` en la ruta admin.

## Best Possible Solution

Separar “shipment creado” de “etiqueta creada”: propagar inmediatamente `carrier`, tracking y `shipmentId`, pero escribir `labelCreatedDate` solo cuando el PDF esté disponible y persistido, conservar un reintento claro para etiquetas diferidas, integrar `dev` y adjuntar prueba runtime redactada.
