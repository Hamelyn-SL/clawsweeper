## Summary

El PR elimina una vía manual aún necesaria para flujos que la documentación vigente declara sin equivalente V2; no debería integrarse hasta completar esa transición o conservar un fallback operativo.

## What This Changes

El PR retira el runtime V1 de sincronización de marketplaces, elimina rutas y estado legacy, y mueve los cronjobs conservados de Amazon y eBay a controladores dedicados.

## Best Possible Solution

Completar en `MarketplaceManager` los flujos de actualización y recuperación pendientes, migrar de forma verificable las filas legacy y retirar V1 solo cuando no queden dependencias operativas.
