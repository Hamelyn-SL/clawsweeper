## Label Justifications

- `P1`: La falta de teléfono del destinatario afecta de forma recurrente a entregas Fnac y dificulta el contacto del transportista.
- `impact:other`: El impacto es operativo en la entrega de pedidos y no encaja con precisión en las clases específicas de sesión, mensajes, proveedor o seguridad.

## Summary

La incidencia sigue siendo necesaria: el importador guarda el teléfono de ATC cuando Fnac no aporta los dos campos de envío esperados. Falta el payload original para confirmar si el teléfono llega en otra clave o no llega desde Fnac.

## What This Changes

Corregir la importación de pedidos Fnac para conservar el teléfono real del cliente cuando esté presente en la respuesta del marketplace.

## Best Possible Solution

Capturar una respuesta `orders_query` anonimizada, ampliar solo el esquema que corresponda y fijar una prioridad explícita de teléfonos con cobertura de regresión, manteniendo el fallback actual cuando Fnac no entregue dato.

## Solution Assessment
