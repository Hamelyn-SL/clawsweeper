## Label Justifications

- `P2`: Es una mejora de rendimiento y navegación importante, pero el flujo actual sigue funcionando y requiere una migración amplia.
- `impact:ux-friction`: Las navegaciones públicas pagan renderizado dinámico completo, aumentando la latencia sin bloquear el acceso a Ecommerce.

## Summary

La necesidad sigue vigente en `dev`: Cache Components no está activado y el layout raíz sigue leyendo datos de petición antes de renderizar el shell. La PR abierta https://github.com/Hamelyn-SL/hamelyn-serverless/pull/8316 concentra la implementación, por lo que esta issue debe permanecer abierta hasta que se revise y aterrice.

## What This Changes

Migrar Ecommerce a Cache Components de Next 16.3 para prerenderizar shells de navegación y aislar por streaming los datos dependientes de cada petición.

## Best Possible Solution

Acordar los límites cacheables y aterrizar la PR enlazada por fases verificables, preservando datos de precio, stock, locale y experimentación como dependientes de petición.
