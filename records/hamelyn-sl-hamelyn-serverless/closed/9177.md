## Summary

Mantener abierto: `dev` aún conserva el backoff global de 45 días y este PR aporta la corrección solicitada. La lógica es acotada y no presenta un defecto concreto, pero la readmisión histórica requiere revisión manual antes de integrar.

## What This Changes

El PR limita a cuatro horas el backoff transitorio de `withdraw`, readmite retiradas históricas y registra errores persistidos de batch por SKU.

## Best Possible Solution

Conservar el techo específico de `withdraw` y añadir una prueba versionada del selector histórico con un motor MongoDB compatible antes de integrar.

## Solution Assessment

Sí, con una validación adicional del selector histórico: separa `withdraw` de publicaciones y cambios de precio sin alterar sus calendarios.
