## Summary

Se mantiene abierta: `dev` no contiene aún el extractor paginado `offers_query`, el script que escriba `fnac_listings` ni el workflow de Fnac solicitado. La infraestructura fusionada mejora snapshots existentes, pero no resuelve esta capacidad nueva.

## What This Changes

Añadir un snapshot completo de listings de Fnac en BigQuery mediante `offers_query`, con deduplicación, guard de volumen, reintentos y workflow cada dos días.

## Best Possible Solution

Añadir un extractor Fnac aislado que valide y deduzca ofertas antes de insertar el snapshot, reutilice el patrón de observabilidad existente y mantenga desactivadas las escrituras Mongo hasta verificar la primera ejecución real.
