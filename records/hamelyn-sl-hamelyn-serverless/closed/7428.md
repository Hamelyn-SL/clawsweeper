## Summary

El issue sigue vigente: en `dev` la app `agents` continúa con integración Git nativa de Vercel y el dispatcher de deploy hooks la excluye explícitamente, así que no hay evidencia de que el problema central esté implementado.

## What This Changes

El issue pide alinear `marketplace-agents` con el despliegue selectivo por deploy hooks del monorepo para evitar deployments en pushes no relacionados.

## Best Possible Solution

Mantener abierto hasta que `agents` esté en el dispatcher de deploy hooks, el despliegue Git nativo quede desactivado y los secrets externos necesarios estén creados y verificados en `dev` y `master`.
